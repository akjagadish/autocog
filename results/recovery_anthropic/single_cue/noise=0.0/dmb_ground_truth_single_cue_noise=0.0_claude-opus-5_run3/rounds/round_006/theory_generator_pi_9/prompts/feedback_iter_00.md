## System Prompt

You are a renowned cognitive scientist critiquing a freshly proposed candidate theory and model in the Decision Making (Binary Features) domain.

The candidate has been simulated on every previously run experiment. For each experiment you are shown the design, the metric, the value the metric takes on real data, and the value it takes on the candidate's simulated data.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the feedback is to SURFACE theories that are EXPERIMENT-INVARIANT: that is,theories that explain data across multiple experiments. 
Your task is to determine whether the candidate captures the human/real behavior well enough across these experiments. Return a verdict:
  * "continue"   — the candidate is good enough; carry on.
  * "regenerate" — the candidate fails to capture the empirical pattern; the proposing agent must produce a new candidate, taking your rationale into account.

Justify the verdict with a concrete diagnosis (which experiments fail, in what direction, what mechanism is likely missing or miscalibrated).

## SCOPE OF YOUR CRITIQUE — STAY INSIDE THE ARBITER'S MECHANISM FAMILY
When an "## ARBITER RECOMMENDATION" block is present below, the proposer was explicitly instructed to implement the mechanism family the arbiter prescribed. Your job is to grade FIT QUALITY *within that prescribed family*, not to relitigate which family should be used — that is the arbiter's call, made one level above this loop.

Concretely:
  * If the candidate misses the data, you may push for MINOR ADJUSTMENTS that keep the prescribed mechanism intact: tightening / widening parameter ranges, adding a temperature, swapping a normalization scheme, fixing a softmax / distance metric, re-balancing attention weights, fixing a learning-rate sign, correcting a bug in the gating or recurrence, etc.
  * You MUST NOT recommend switching to a different mechanism family. Such a switch is the arbiter's prerogative; recommending it here will mislead the proposer into oscillating between families across iterations.
  * Also grade FAITHFULNESS to the recommendation explicitly: if the candidate has clearly drifted into a different family than the one prescribed, say so in the rationale and ask for a return to the prescribed family — again, with minor adjustments, not a re-design.

## ACCEPT GATE — HOW THE LOOP DECIDES WHAT TO BUILD ON NEXT
This propose-loop has a programmatic accept gate. After every iteration the candidate's `aggregate_loss` is compared against the running-best loss (`accepted_loss`):
  * `loss < accepted_loss` → ACCEPTED. The candidate becomes the new running-best base; the next iteration's proposer will build on THIS candidate.
  * `loss >= accepted_loss` → REJECTED. The base is unchanged; the next iteration's proposer will build on the SAME `accepted` candidate again, with your new feedback on top. Rejected candidates are discarded — the loop guarantees the base never regresses, so you do NOT need to ask the proposer to "revert" anything; that already happens for free.

Two consequences for your verdict:
  * If the candidate you are grading was REJECTED by the gate, returning `"continue"` is silently downgraded to `"regenerate"` (returning a worse candidate would defeat the gate). Spend your rationale on a NEW direction the proposer should try on top of the unchanged accepted base, not on defending the rejected attempt.
  * If the candidate was ACCEPTED, you can return `"continue"` to stop the loop and ship this candidate, or `"regenerate"` to keep tuning further.

## LEARN FROM YOUR OWN PAST ADVICE
When a "## YOUR PRIOR CRITIQUES" block is present below, each prior iteration ends with an "Outcome of your advice" line that says whether the next candidate the proposer produced was ACCEPTED (your advice helped — its loss strictly beat the running best) or REJECTED (your advice didn't help — the proposer discarded the result and reset to the previous accepted base). This is the loop's ground-truth signal on whether *your own previous critique was good*. Use it explicitly:
  * If a previous piece of advice was ACCEPTED, it is OK to repeat / extend it. Reinforce in the same direction.
  * If a previous piece of advice was REJECTED, do NOT repeat the same recommendation; in your new rationale, briefly acknowledge that the previous push in that direction was rejected by the gate and try a different in-family knob (or a smaller step in the same direction) instead.
  * If you find yourself oscillating (e.g. iter 1 said "increase α", iter 2 said "decrease α", iter 3 about to say "increase α" again), STOP and recommend a value between the two flanking iterations instead.
  * The "## LOSS TRAJECTORY" block at the top of the user prompt summarises the same information at the loop level — consult it before issuing a new regenerate-with-direction recommendation.

## CANDIDATE THEORY
**Noisy compensatory reason-counting with FLATTENED diagnosticity, a saturating numerosity bonus, a REVERSIBLE gap inference, an authority-capped top-down entry, and a hard read-out ceiling.**

The subject reads a two-column panel and forms a *drive* toward one product; the drive is then squashed by a hard noise ceiling, so no display — however lopsided — ever yields more than ~.85-.90 confidence. Six commitments:

1. **Diagnosticity is read coarsely.** Each discriminating expert contributes x_j = ((v_j-.5)/.5)^rho with rho ~.65-.90, i.e. stated validity is compressed: a .95 oracle is worth only ~1.7-2.0 mid experts rather than 4-5. Numerosity therefore routinely outweighs a single oracle (three mid experts beat it comfortably; two roughly tie it). There is no unanimity term: a landslide is just a big tally, not a categorical fact.

2. **'More experts back this one' is a single, discrete, saturating extra reason.** M = lam*sign(k_A-k_B)*min(max(|dk|-1,0),1): it fires once at a two-reason edge and never grows, so a five-against-one panel is not treated as five times more compelling than a three-against-one panel.

3. **Screen position is a tie-breaker, not an attention driver.** Symmetric edge salience s_j = exp(-j/tau)+exp(-(n-1-j)/tau) enters with a count-contingent gain g = g_res + (1-g_res)*exp(-dk^2/2sigma^2). When the reasons are exactly deadlocked the first and last rows of the panel decide; as soon as one side has more reasons the edge bonus shrinks to a small constant residual (g_res ~.13) and can no longer overturn a numerical majority. Position never captures the read (no top-row lottery, no limited-sample reading): its whole behavioural footprint is confined to displays whose reason counts tie.

4. **Gap inference from panel silence is GRADED AND REVERSIBLE.** Validity is read as sensitivity. A difference that only a hyper-sensitive expert notices while the rest of the panel positively says 'these are alike' implies a negligible true gap — and, past a point, it implies the endorsement is spurious. Formally the credibility multiplier is c = 1 - eta*f_sil^q*vbar, a smooth power function of the silent fraction (mutual endorsements count as silence at weight omega < 1) with no step, no threshold and no positive floor: c is allowed to pass through zero into a small negative region (floored at c_neg ~ -0.35). This is the *only* mechanism in the model that can make people choose against a lone endorsement, and it fires only in the narrow corner where almost the whole panel is mute and the single speaker is the most sensitive expert on it. Because omega < 1, densely endorsed panels are read as slightly more informative than sparsely endorsed ones, which produces a small positive load effect rather than none.

5. **Top-down entry with an authority cap.** People start reading at the top of the panel and will commit to the first row that discriminates, but only if no more diagnostic expert remains below it. When the display happens to be ordered by validity this route runs almost always and behaviour looks lexicographic; when the strongest expert sits lower down the route is suppressed and behaviour is compensatory. The committed choice inherits the same credibility multiplier c, so a committed but incredible cue produces a near-coin-flip (or a mild reversal when c < 0).

6. **Compressive read-out with a fixed lapse ceiling and a mild dilution.** The drive is divided by (number of speaking experts)^psi (sparse panels are slightly, never categorically, less decisive) and passed through a logistic with gain beta, then mixed with a substantial lapse epsilon ~.14-.24, bounding P(choice) roughly in [.12, .88]. Individual differences are unimodal jitter in rho, lam, mu, g_res, eta, omega, c_neg, beta, d_com and the lapse rate; no strategy subpopulations, no learning.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np

    # ------------------------------------------------------------------
    # 1. parse the trial stimulus into two rating vectors (screen order)
    # ------------------------------------------------------------------
    a = None
    b = None
    if isinstance(state, dict):
        if 'option_a_ratings' in state and 'option_b_ratings' in state:
            a = np.asarray(list(state['option_a_ratings']), dtype=float)
            b = np.asarray(list(state['option_b_ratings']), dtype=float)
    if a is None:
        arr = np.asarray(state, dtype=float)
        arr = arr.reshape(2, -1)
        a = arr[0].astype(float)
        b = arr[1].astype(float)

    a = np.ravel(a).astype(float)
    b = np.ravel(b).astype(float)
    n = int(min(a.shape[0], b.shape[0]))
    if n == 0:
        return np.array([0.5, 0.5])
    a = a[:n]
    b = b[:n]
    d = a - b
    disc = np.abs(d) > 1e-12
    if not np.any(disc):
        return np.array([0.5, 0.5])

    # ------------------------------------------------------------------
    # 2. communicated validities -> scaled diagnosticity
    # ------------------------------------------------------------------
    val = parameters.get('validities', None)
    try:
        val = np.asarray(val, dtype=float).ravel()
    except Exception:
        val = None
    if val is None or val.shape[0] != n:
        val = np.linspace(0.95, 0.55, n) if n > 1 else np.array([0.90])
    val = np.clip(val, 0.5 + 1e-6, 1.0 - 1e-9)
    vs = np.clip((val - 0.5) / 0.5, 1e-6, 1.0)

    # ------------------------------------------------------------------
    # 3. parameters
    # ------------------------------------------------------------------
    def _p(key, dflt, lo, hi):
        try:
            v = float(parameters.get(key, dflt))
        except Exception:
            v = float(dflt)
        if not np.isfinite(v):
            v = float(dflt)
        return float(np.clip(v, lo, hi))

    rho = _p('rho', 0.78, 0.05, 4.0)
    lam = _p('lam', 0.52, 0.0, 3.0)
    mu = _p('mu', 1.20, 0.0, 6.0)
    tau = _p('tau', 1.00, 0.2, 8.0)
    sig_g = _p('sigma', 0.55, 0.15, 3.0)
    g_res = _p('g_res', 0.13, 0.0, 1.0)
    eta = _p('eta', 2.40, 0.0, 8.0)
    q_sil = _p('q_sil', 2.60, 1.0, 8.0)
    om = _p('omega', 0.80, 0.0, 1.0)
    c_neg = _p('c_neg', -0.35, -1.5, 0.5)
    psi = _p('psi', 0.15, 0.0, 1.0)
    beta = _p('beta', 1.40, 0.05, 40.0)
    d_com = _p('d_com', 2.20, 0.2, 8.0)
    phi = _p('phi', 1.05, 0.5, 3.0)
    s_stop = _p('s_stop', 12.0, 0.5, 60.0)
    eps = _p('epsilon', 0.19, 0.0, 0.5)

    def _sig(z):
        return 1.0 / (1.0 + np.exp(-np.clip(z, -60.0, 60.0)))

    # ------------------------------------------------------------------
    # 4. reason count with COMPRESSED diagnosticity (no position here)
    # ------------------------------------------------------------------
    x = np.power(vs, rho)
    idxs = np.flatnonzero(disc)
    m = int(idxs.shape[0])
    sgn = np.sign(d[idxs])
    xs = x[idxs]
    V = float(np.sum(sgn * xs))

    kA = int(np.count_nonzero(sgn > 0))
    kB = int(np.count_nonzero(sgn < 0))
    dk = float(kA - kB)

    # ------------------------------------------------------------------
    # 5. saturating numerosity bonus (fires once, at |dk| >= 2)
    # ------------------------------------------------------------------
    Mb = lam * (1.0 if dk > 0 else (-1.0 if dk < 0 else 0.0)) \
         * float(min(max(abs(dk) - 1.0, 0.0), 1.0))

    # ------------------------------------------------------------------
    # 6. symmetric edge salience, active mainly on deadlocked counts
    # ------------------------------------------------------------------
    pos = np.arange(n, dtype=float)
    s_sal = np.exp(-pos / tau) + np.exp(-(n - 1.0 - pos) / tau)
    S = float(np.sum(sgn * s_sal[idxs]))
    g = g_res + (1.0 - g_res) * float(np.exp(-np.clip((dk * dk) / (2.0 * sig_g * sig_g), 0.0, 60.0)))
    Pterm = mu * g * S

    # ------------------------------------------------------------------
    # 7. graded, REVERSIBLE gap inference (validity = sensitivity)
    # ------------------------------------------------------------------
    both1 = (~disc) & (a > 0.5) & (b > 0.5)
    both0 = (~disc) & (~both1)
    f_sil = (float(np.count_nonzero(both0)) + om * float(np.count_nonzero(both1))) / float(n)
    f_sil = float(np.clip(f_sil, 0.0, 1.0))
    tot = float(np.sum(xs))
    if tot <= 1e-12:
        return np.array([0.5, 0.5])
    vbar = float(np.sum(xs * vs[idxs]) / tot)
    c = 1.0 - eta * (f_sil ** q_sil) * vbar
    c = float(max(c, c_neg))

    # ------------------------------------------------------------------
    # 8. mild dilution by the number of speaking experts + read-out
    # ------------------------------------------------------------------
    denom = float(m) ** psi if m > 0 else 1.0
    drive = (V + Mb + Pterm) / max(denom, 1e-9)
    p_int = float(_sig(beta * c * drive))

    # ------------------------------------------------------------------
    # 9. authority-capped top-down entry
    # ------------------------------------------------------------------
    j1 = int(idxs[0])
    if j1 >= n - 1:
        q_com = 1.0
    else:
        v_rest = float(np.max(vs[j1 + 1:]))
        v_rest = max(v_rest, 1e-6)
        ratio = float(vs[j1]) / (phi * v_rest)
        q_com = float(_sig(s_stop * (ratio - 1.0)))
    q_com = float(np.clip(q_com, 0.0, 1.0))

    p_dec = float(_sig(beta * c * d_com))
    p_com_a = p_dec if d[j1] > 0 else (1.0 - p_dec)

    p_a = q_com * p_com_a + (1.0 - q_com) * p_int

    p = np.array([p_a, 1.0 - p_a], dtype=float)
    p = (1.0 - eps) * p + eps * 0.5
    p = np.clip(p, 1e-12, None)
    p = p / p.sum()
    return p

def policy(probs):
    import numpy as np
    probs = np.asarray(probs, dtype=np.float64)
    probs = np.clip(probs, 0.0, None)
    s = probs.sum()
    if not np.isfinite(s) or s <= 0:
        probs = np.ones_like(probs) / len(probs)
    else:
        probs = probs / s
    return int(np.random.choice(len(probs), p=probs))

**Where I deliberately deviate, and why.** Two of the arbiter's prescriptions are contradicted by the corpus itself.

*(1) Position must be count-contingent, not uniform.* A uniformly applied edge bonus cannot simultaneously produce Exp 10 (.85 for two screen-extreme cues when the reason count is 2-2) and Exp 9 (.49, where the same extremes lose once they are outnumbered 2-3), or Exp 3/Exp 4 (~.51, extremes vs one strong cue at a one-reason edge). *(2) A lexicographic route must survive, but only when the top row is also the authority.* Exp 1's observed +.093 means TTB-consistency is *equal* on tally-agreeing and tally-conflicting trials — only near-lexicographic behaviour can do that, and Exp 1 is precisely the design whose validities descend down the screen. Deleting the authority-capped first-cue route (as suggested) drops Exp 1 to about -.48, a catastrophic regression on a metric where the whole theory field spans [-.69, +.10]. Keeping the *authority cap* is what reconciles Exp 1 with Exp 2 and Exp 13: when the strongest expert is not at the top (Exp 2's .95 sits at the bottom row; Exp 13's top rows are cheap) the route is suppressed and behaviour is compensatory, giving tally-following .78 and top-row-following ~.30 rather than pi_8's refuted .93.

**The genuinely new mechanism.** Panel credibility c = 1 - eta*f_sil^q*vbar is graded (a smooth power function, no step, no threshold) and, crucially, is allowed to pass through zero into a small negative region instead of being floored at a positive constant. Cognitively: if the *only* expert who sees a difference is the most sensitive one while everyone else positively asserts the products are alike, the lone endorsement is discounted to nothing and then read as evidence that the difference is an artefact. This fires only in a narrow corner (silent fraction above ~.75 with a high-validity lone speaker) and it is what delivers Exp 8's reversal quantitatively: my hand-simulation gives weak-cue following ~.70 and strong-cue following ~.48, i.e. a contrast of about -.22 against the observed -.2025 — obtained without pi_7's arbitrary positive floor and without any categorical gate. Because mutual endorsements count as silence only at weight omega < 1, the same term produces the small positive load effect observed in Exp 7 (+.05) where pi_7 produced -.07.

Overall this is a compensatory tally in the same family the arbiter asked for — flatter validity weighting, saturating majority, no unanimity, explicit noise ceiling, graded rather than categorical panel inference — with the two count- and authority-contingent qualifications that the data (Exp 1, 9, 10) demand. def metric(data: pd.DataFrame) -> float:
```python
    import numpy as np
    import pandas as pd

    dis_hits = 0.0
    dis_n = 0.0
    agr_hits = 0.0
    agr_n = 0.0

    for a_raw, b_raw, resp in zip(data['option_a_ratings'],
                                  data['option_b_ratings'],
                                  data['response']):
        a = np.asarray(a_raw, dtype=float)
        b = np.asarray(b_raw, dtype=float)
        if a.shape != b.shape or a.size == 0:
            continue

        # Take-The-Best winner: features are listed in descending validity
        # order, so scan left to right for the first discriminating cue.
        ttb_winner = None
        for j in range(a.size):
            if a[j] > b[j]:
                ttb_winner = 0
                break
            if b[j] > a[j]:
                ttb_winner = 1
                break
        if ttb_winner is None:
            continue

        a_wins = float(np.sum(a > b))
        b_wins = float(np.sum(b > a))
        if a_wins == b_wins:
            continue  # tally-tie pairs excluded (uninformative for the contrast)
        tally_winner = 0 if a_wins > b_wins else 1

        try:
            r = int(resp)
        except (TypeError, ValueError):
            continue
        hit = 1.0 if r == ttb_winner else 0.0

        if tally_winner != ttb_winner:
            dis_hits += hit
            dis_n += 1.0
        else:
            agr_hits += hit
            agr_n += 1.0

    if dis_n == 0.0 or agr_n == 0.0:
        return float('nan')

    return float(dis_hits / dis_n - agr_hits / agr_n)
```

```python
    import pandas as pd
```

```python
    def ttb_winner(a, b, val):
        order = np.argsort(-val, kind='stable')
        for j in order:
            if a[j] > b[j]:
                return 0
            if b[j] > a[j]:
                return 1
        return None

    def scan_sign(d, lam):

        pos = np.arange(n, dtype=float)
        z = -lam * (pos - pos.mean())
        z = z - z.max()
        w = np.exp(z)
        num = float(np.sum(w * d))
        den = float(np.sum(w * np.abs(d)))
        if den <= 1e-12:
            return 0.0
        return num / den

            b = np.asarray(list(row['option_b_ratings']), dtype=float)
```
