**Description:** Decision makers employ a Thresholded Weighted Additive (WADD) strategy. Instead of integrating all available information or relying entirely on a single cue, subjects impose a depth-of-processing limit by ignoring features whose validities fall below a subjective threshold. Features that exceed this threshold are integrated into a compensatory sum weighted by a non-linear transformation of their validities. By allowing the threshold to be arbitrarily low and constraining the non-linear scaling, the model captures bounded rationality while avoiding an over-reliance on a single best cue.

**Rationale:** Following the critic's feedback, the Thresholded WADD model has been refined to address the under-prediction in Exp 6 and the over-prediction in Exps 3 and 5. The range for the validity threshold `theta` was expanded to [0.0, 1.0], allowing the model the flexibility to integrate all cues (recovering standard WADD) if the data demands it. Furthermore, the upper bound of the non-linear scaling parameter `gamma` was reduced from 5.0 to 3.0 to prevent the model from hyper-weighting the top surviving cues and mimicking TTB too closely. These minimal parameter constraint edits provide a softer transition between full integration and selective thresholding.

**Parameters:**
  - `beta`: `[0.01, 10.0]`
  - `gamma`: `[0.0, 3.0]`
  - `theta`: `[0.0, 1.0]`

```python
    e_wadd = np.exp(z_wadd)
    p_wadd = e_wadd / np.sum(e_wadd)

    return p_final
```

### slot 2 — `pi_4` — SURVIVED ✓

**Description:** Decision makers employ a dual-process or strategy mixture approach when evaluating multi-attribute options. Rather than relying entirely on a single strategy, choices are generated by a probabilistic mixture of a simple, unweighted Tallying heuristic (which counts the number of strictly winning features) and a compensatory Weighted Additive (WADD) strategy (which integrates all features weighted by their subjective validities). To ensure equitable application of choice determinism, the evidence scores for both strategies are normalized to a common [0, 1] scale before applying a shared inverse temperature parameter. The mixture parameter 'alpha' dictates the reliance on Tallying versus WADD, allowing the model to capture exact chance-level responding in scenarios where features tie while maintaining sensitivity to cue validities in general.

**Rationale:** Following the critic's advice, this minimal edit normalizes the evidence scores for both Tallying and WADD to a common [0, 1] range. For Tallying, the win counts are divided by the total number of features. For WADD, the weighted sums are divided by the sum of all subjective validities. This resolves the scale mismatch between integer counts and exponentiated weights, allowing the model to use a single shared inverse-temperature parameter ('beta') efficiently without unnatural scaling artifacts or the need for extra degrees of freedom.

**Parameters:**
  - `beta`: `[0.01, 10.0]`
  - `gamma`: `[0.0, 5.0]`
  - `alpha`: `[0.0, 1.0]`
  - `epsilon`: `[0.0, 0.5]`
  - `validities`: `validities`

```python
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:

    a, b = stim[0], stim[1]
    n_features = stim.shape[1]
    
    val = np.asarray(parameters["validities"], dtype=float)
    gamma = float(parameters["gamma"])
    beta = float(parameters["beta"])
    alpha = float(parameters["alpha"])
    epsilon = float(parameters["epsilon"])
    
    # WADD Component: Weighted sum using non-linearly scaled validities, normalized to [0, 1]
    subjective_weights = val ** gamma
    sum_weights = np.sum(subjective_weights)
    score_a_wadd = np.sum(a * subjective_weights) / sum_weights

    scores_wadd = np.array([score_a_wadd, score_b_wadd])

    e_tally = np.exp(z_tally)
    p_tally = e_tally / np.sum(e_tally)
    
    # Mixture of the two strategies
    p_mixed = alpha * p_tally + (1.0 - alpha) * p_wadd
    
    # Incorporate response noise (lapse rate)
    return (1.0 - epsilon) * p_mixed + epsilon * np.array([0.5, 0.5])
```

### `pi_7` → slot 1 (via `new_theory`)

**Description:** Rank-Weighted Integration: Decision-makers rely on the ordinal rank of cue validities rather than their raw numeric values. Features are integrated into a compensatory sum, but each feature's weight decays exponentially according to its rank. To reflect boundedly rational yet compensatory behavior, the decay is bounded away from zero, ensuring lower-ranked features still contribute meaningfully rather than collapsing into pure Take-The-Best behavior.

**Rationale:** Following the critic's advice, I reduced the 'beta' parameter range to [0.5, 5.0] to prevent overly deterministic choices and reduce overprediction of effect magnitudes observed in multiple experiments. I also tightened the 'decay' parameter range to [0.7, 1.0] to further encourage compensatory integration and correct the directional error in Experiment 6 by preventing top cues from dominating too much.

**Parameters:**
  - `beta`: `[0.5, 5.0]`
  - `decay`: `[0.7, 1.0]`
  - `epsilon`: `[0.0, 0.5]`
  - `validities`: `validities`

**`predict(parameters, stimulus, history)`:**

```python
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) state; got shape {stim.shape}.")
    
    a, b = stim[0], stim[1]
    
    val = np.asarray(parameters["validities"], dtype=float)
    decay = float(parameters["decay"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Determine the ordinal rank of each feature's validity (0 = most valid)
    # np.argsort sorts ascending; [::-1] makes it descending
    order = np.argsort(val)[::-1]
    ranks = np.zeros_like(val, dtype=float)
    ranks[order] = np.arange(len(val))
    
    # Exponentially decay weights based on rank
    # If decay is 0.0, 0.0**0 is 1.0 and 0.0**>0 is 0.0 (Take-The-Best)
    # If decay is 1.0, 1.0**rank is 1.0 for all (Tallying)
    weights = decay ** ranks
    
    sum_weights = np.sum(weights)
    if sum_weights > 0:
        score_a = np.sum(a * weights) / sum_weights
        score_b = np.sum(b * weights) / sum_weights
    else:
        score_a, score_b = 0.5, 0.5
        
    scores = np.array([score_a, score_b])
    
    # Softmax choice rule
    z = beta * (scores - np.max(scores))
    e = np.exp(z)
    p = e / np.sum(e)
    
    # Incorporate lapse rate
    p_final = (1.0 - epsilon) * p + epsilon * np.array([0.5, 0.5])
    
    return p_final
```
