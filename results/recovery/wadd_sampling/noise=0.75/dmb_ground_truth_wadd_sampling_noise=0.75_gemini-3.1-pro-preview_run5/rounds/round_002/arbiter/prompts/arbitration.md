# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_4" and "pi_3") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_4" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_3" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_4
Dual Process Strategy Mixture: Decision-makers employ different strategies probabilistically. A proportion of choices are generated by a strict, non-compensatory 'Take-The-Best' (TTB) heuristic, while the remainder are generated by a compensatory 'Tallying' strategy. The Tallying component operates with softer inverse temperatures, preventing it from producing excessively extreme compensatory shifts when multiple weak cues oppose a strong one, while the TTB component operates with high determinism.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, stimulus, history):
    import numpy as np
    
    stim = np.asarray(stimulus, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError("Stimulus must be shape (2, n_features).")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    # Strategy 1: Take-The-Best (TTB)
    cue_order = np.argsort(-val, kind="stable").tolist()
    winner_ttb = None
    for j in cue_order:
        if a[j] > b[j]:
            winner_ttb = 0
            break
        if b[j] > a[j]:
            winner_ttb = 1
            break
            
    if winner_ttb == 0:
        scores_ttb = np.array([1.0, 0.0])
    elif winner_ttb == 1:
        scores_ttb = np.array([0.0, 1.0])
    else:
        scores_ttb = np.array([0.0, 0.0])
        
    beta_ttb = float(parameters["beta_ttb"])
    z_ttb = beta_ttb * (scores_ttb - np.max(scores_ttb))
    e_ttb = np.exp(z_ttb)
    p_ttb = e_ttb / np.sum(e_ttb)
    
    # Strategy 2: Tallying
    a_wins = float(np.sum(a > b))
    b_wins = float(np.sum(b > a))
    scores_tally = np.array([a_wins, b_wins])
    
    beta_tally = float(parameters["beta_tally"])
    z_tally = beta_tally * (scores_tally - np.max(scores_tally))
    e_tally = np.exp(z_tally)
    p_tally = e_tally / np.sum(e_tally)
    
    # Mixture
    w_ttb = float(parameters["w_ttb"])
    p_mix = w_ttb * p_ttb + (1.0 - w_ttb) * p_tally
    
    # Lapse noise
    epsilon = float(parameters["epsilon"])
    p_final = (1.0 - epsilon) * p_mix + epsilon * np.array([0.5, 0.5])
    
    return p_final

def policy(probabilities):
    import numpy as np
    probabilities = np.asarray(probabilities, dtype=np.float64)
    probabilities /= probabilities.sum()
    return int(np.random.choice(len(probabilities), p=probabilities))

## THEORY 2 — pi_3
Weighted Additive (WADD) Theory with Subjective Validity Scaling: People compare options by computing a comprehensive value for each option, integrating all available cues by weighting each feature. However, instead of using raw objective validities, individuals apply a non-linear subjective scaling to these validities. This scaling allows a single highly valid cue to be disproportionately weighted to balance out multiple less valid cues, gracefully explaining why individuals exhibit near-indifference (choice proportions around 0.5) when faced with adversarial choices where one option excels on the best cue but the other excels on numerous lesser cues. Response noise is captured via a softmax over the options' weighted sums, along with an independent lapse rate.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, stimulus, history):
    import numpy as np
    stim = np.asarray(stimulus, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"WADD expects a (2, n_features) stimulus; got shape {stim.shape}.")
    
    val = np.asarray(parameters["validities"], dtype=float)
    if val.shape[0] != stim.shape[1]:
        raise ValueError("Length of validities must match n_features.")
    
    # Apply non-linear subjective scaling to validities
    gamma = float(parameters["gamma"])
    val = val ** gamma
    
    a, b = stim[0], stim[1]
    
    # Compute weighted additive values for each option
    score_a = np.sum(a * val)
    score_b = np.sum(b * val)
    scores = np.array([score_a, score_b])
    
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Softmax choice rule with max-subtraction for numerical stability
    z = beta * (scores - np.max(scores))
    e = np.exp(z)
    p_core = e / np.sum(e)
    
    n_opts = p_core.shape[0]
    return (1.0 - epsilon) * p_core + epsilon * (np.ones(n_opts) / n_opts)

  trial 8: A=[1, 0, 0, 1, 0, 0]  B=[0, 0, 0, 0, 1, 0]

**Rationale:** This design tests the core assumption of the Dual Process Strategy Mixture (TTB + Tallying) against WADD by holding both the TTB-favored cue and the Tallying count differences constant across matched pairs, while varying the validities of the secondary cues. The Mixture theory predicts identical choice probabilities within these matched pairs because TTB only processes the top discriminating cue (which is identical) and Tallying only processes the number of winning cues (which is identical). In contrast, WADD integrates the subjective validities of all cues, predicting significant differences within the matched pairs because the secondary cues have different validities.

**Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
The experimental design contains matched pairs of trials where the Take-The-Best cue and the Tallying counts are identical, but the validities of the secondary cues differ. The Dual Process Strategy Mixture (TTB + Tallying) predicts identical choice probabilities within these pairs because both heuristics ignore the specific validities of the secondary cues once the primary cue or tally is established. WADD, however, integrates all validities, predicting systematic differences. By summing the signed differences in choice proportions for Option B across these matched pairs, we expect a value near 0 for the Mixture theory, but a significantly positive value for WADD.

    data['trial_str'] = data['option_a_ratings'].apply(lambda x: ''.join(map(str, x))) + '_' + data['option_b_ratings'].apply(lambda x: ''.join(map(str, x)))
    
    # Calculate the proportion of times Option B was chosen for each trial type
    p_b = data.groupby('trial_str')['response'].mean()
    
    # Matched pair 1
    t1 = '101000_010100'
    t2 = '100010_010001'
    
    # Matched pair 2
    t3 = '100000_011000'
    t4 = '100000_000110'
    
    # Matched pair 3
    t5 = '100000_011100'
    t6 = '100000_001110'
    
    diff = 0.0
    
    # WADD predicts P(B) is higher in t2 than t1, t3 than t4, and t5 than t6.
    # The Dual Process Mixture predicts identical probabilities within these pairs.

    if t5 in p_b and t6 in p_b:
        diff += (p_b[t5] - p_b[t6])
        
    return float(diff)

**Rationale:** This design isolates a critical qualitative dissociation between the Dual Process Strategy Mixture and WADD with subjective scaling. In key trials, Option A possesses the single highest-validity discriminating cue (causing TTB to favor A) AND a greater total number of winning cues (causing Tallying to favor A). Consequently, the Mixture model is strictly constrained to predict a preference for Option A. However, Option B is supported by multiple highly valid cues that are only marginally inferior to Option A's single top cue. Under WADD with a non-linear subjective validity scaling (e.g., gamma > 1), the combined weight of Option B's multiple strong cues surpasses Option A's single top cue and weak secondary cues, allowing WADD to predict a preference for Option B. This creates a scenario where the two theories predict choices in opposite directions.

**Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
This metric isolates trials where Option A has the single best cue AND a greater total number of positive cues than Option B (Trials 1-4). Under the Dual Process Strategy Mixture theory, both the Take-The-Best heuristic and the Tallying strategy unanimously favor Option A, constraining the model to predict an overwhelming preference for Option A (proportion of B choices near 0). Conversely, under the WADD theory with subjective validity scaling, a sufficiently large non-linear scaling parameter (gamma) causes Option B's multiple strong secondary cues to outweigh Option A's single top cue, leading to a substantial proportion of choices for Option B. Thus, measuring the choice proportion for Option B on these specific trials maximally discriminates the two theories.

def metric(data: pd.DataFrame) -> float:
    # Identify trials where Option A has >= 3 positive cues and Option B has exactly 2
    a_sums = data['option_a_ratings'].apply(lambda x: sum(x))
    b_sums = data['option_b_ratings'].apply(lambda x: sum(x))
    
    mask = (b_sums == 2) & (a_sums >= 3)
    
    if mask.sum() == 0:
        return 0.0
        
    # Return the proportion of times Option B was chosen
    return float(data.loc[mask, 'response'].mean())

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    import pandas as pd
    
    ttb_chose_winner = []
    opposing_cues = []
    
    for _, row in data.iterrows():
        a = row['option_a_ratings']
        b = row['option_b_ratings']
        
        winner_ttb = None
        for j in range(len(a)):
            if a[j] > b[j]:
                winner_ttb = 0
                break
            elif b[j] > a[j]:
                winner_ttb = 1
                break
                
        if winner_ttb is None:
            continue
            
        opp = 0
        for j in range(len(a)):
            if winner_ttb == 0 and b[j] > a[j]:
                opp += 1
            elif winner_ttb == 1 and a[j] > b[j]:
                opp += 1
                
        opposing_cues.append(opp)
        ttb_chose_winner.append(1 if row['response'] == winner_ttb else 0)
        
    df = pd.DataFrame({'opp': opposing_cues, 'chose_ttb': ttb_chose_winner})
    
    p_1 = df[df['opp'] == 1]['chose_ttb'].mean()
    p_3 = df[df['opp'] >= 3]['chose_ttb'].mean()
    
    if pd.isna(p_1) or pd.isna(p_3):
        return 0.0
        
    return float(p_1 - p_3)
```

def metric(data: pd.DataFrame) -> float:
    # Identify which option is favored by Take The Best (the one with 1 on the top cue)
    ttb_favored_is_A = data['option_a_ratings'].apply(lambda x: x[0] == 1)
    ttb_match = ((data['response'] == 0) == ttb_favored_is_A).astype(float)
    
    # Extract the features of the opposing (non-TTB-favored) option
    def get_opponent(row):
        if row['option_a_ratings'][0] == 1:
            return tuple(row['option_b_ratings'])
        else:
            return tuple(row['option_a_ratings'])
            
    opp = data.apply(get_opponent, axis=1)
    
    # Trials where the opposing option is very weak (only has the 5th best cue)
    weak_opp = opp == (0, 0, 0, 0, 1)
    # Trials where the opposing option is very strong (has both the 2nd and 3rd best cues)
    strong_opp = opp == (0, 1, 1, 0, 0)
    
    val_weak = ttb_match[weak_opp].mean() if weak_opp.any() else 0.5
    val_strong = ttb_match[strong_opp].mean() if strong_opp.any() else 0.5
    
    # Return the difference in choice probability for the TTB-favored option
    return float(val_weak - val_strong)
```
