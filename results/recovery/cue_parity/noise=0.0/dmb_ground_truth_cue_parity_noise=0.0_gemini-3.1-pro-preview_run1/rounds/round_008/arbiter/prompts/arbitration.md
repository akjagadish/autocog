# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_10" and "pi_9") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_10" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_9" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_10
Heuristic Toolbox / Strategy Selection Theory with Graded Sub-models: Decision-makers possess a repertoire of distinct decision heuristics (Take-The-Best, Tallying, and Weighted Additive). Instead of assuming pure determinism within each heuristic, each strategy produces graded choice probabilities via a softmax rule applied to its internal evidence (e.g., validity of the discriminating cue for TTB, cue sum for Tallying, log-odds sum for WADD) using a shared choice temperature. Individuals probabilistically select one of these softened heuristics on any given trial.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    w_ttb = float(parameters["w_ttb"])
    w_tally = float(parameters["w_tally"])
    w_wadd = float(parameters["w_wadd"])
    beta_choice = float(parameters["beta_choice"])
    epsilon = float(parameters["epsilon"])
    
    # Normalize weights to get mixture probabilities for the strategies
    total_w = w_ttb + w_tally + w_wadd + 1e-9
    p_ttb = w_ttb / total_w
    p_tally = w_tally / total_w
    p_wadd = w_wadd / total_w
    
    # Strategy 1: Take-The-Best (TTB) Evidence
    order = np.argsort(val)[::-1]
    ttb_score_a, ttb_score_b = 0.0, 0.0
    for idx in order:
        if a[idx] > b[idx]:
            ttb_score_a, ttb_score_b = val[idx], 0.0
            break
        elif b[idx] > a[idx]:
            ttb_score_a, ttb_score_b = 0.0, val[idx]
            break
            
    z_ttb = beta_choice * np.array([ttb_score_a, ttb_score_b])
    z_ttb -= np.max(z_ttb)
    e_ttb = np.exp(z_ttb)
    ttb_probs = e_ttb / np.sum(e_ttb)
    ttb_a, ttb_b = ttb_probs[0], ttb_probs[1]
            
    # Strategy 2: Tallying (Equal Weights) Evidence
    sum_a = np.sum(a)
    sum_b = np.sum(b)
    
    z_tally = beta_choice * np.array([sum_a, sum_b])
    z_tally -= np.max(z_tally)
    e_tally = np.exp(z_tally)
    tally_probs = e_tally / np.sum(e_tally)
    tally_a, tally_b = tally_probs[0], tally_probs[1]
        
    # Strategy 3: Weighted Additive (WADD) Evidence
    val_clipped = np.clip(val, 0.501, 0.999)
    w = np.log(val_clipped / (1.0 - val_clipped))
    score_a = np.sum(a * w)
    score_b = np.sum(b * w)
    
    z_wadd = beta_choice * np.array([score_a, score_b])
    z_wadd -= np.max(z_wadd)
    e_wadd = np.exp(z_wadd)
    wadd_probs = e_wadd / np.sum(e_wadd)
    wadd_a, wadd_b = wadd_probs[0], wadd_probs[1]
        
    # Probabilistic mixture of discrete strategy predictions
    p_A_core = p_ttb * ttb_a + p_tally * tally_a + p_wadd * wadd_a
    p_B_core = p_ttb * ttb_b + p_tally * tally_b + p_wadd * wadd_b
    p_core = np.array([p_A_core, p_B_core])
    
    # Apply lapse rate
    return (1.0 - epsilon) * p_core + epsilon * np.array([0.5, 0.5])

    probabilities /= probabilities.sum()
    return np.random.choice(len(probabilities), p=probabilities)


## THEORY 2 — pi_9
Decision-makers use a Sequential Evidence Accumulation strategy with a stopping rule. They inspect features one by one in descending order of their validity, maintaining a running sum of the differences between the options. If the absolute accumulated evidence reaches or exceeds a specific threshold, they stop and make a choice based on that evidence. If the threshold is not reached, they evaluate all features and decide based on the final tally. This allows the model to smoothly transition between Take-The-Best (low threshold) and Tallying (high threshold) behaviors.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    # Order features by validity descending
    order = np.argsort(val)[::-1]
    
    threshold = float(parameters["threshold"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    diff = a - b
    accumulated_evidence = 0.0
    
    for idx in order:
        accumulated_evidence += diff[idx]
        if abs(accumulated_evidence) >= threshold and abs(accumulated_evidence) > 0:
            break
            
    scores = np.array([accumulated_evidence, -accumulated_evidence])
    
    z = beta * scores
    z -= np.max(z)
    p_core = np.exp(z) / np.sum(np.exp(z))
    
    return (1.0 - epsilon) * p_core + epsilon * np.array([0.5, 0.5])

## EXPERIMENT 1 (proposed by pi_10)

### DESIGN
**Validities (n_features=5):** [0.95, 0.9, 0.85, 0.6, 0.55]

**Trial pairs (n=7):**
  trial 1: A=[1, 0, 0, 1, 1]  B=[0, 1, 1, 0, 0]
  trial 2: A=[0, 1, 1, 0, 0]  B=[1, 0, 0, 1, 1]
  trial 3: A=[1, 0, 0, 0, 1]  B=[0, 1, 1, 0, 0]
  trial 4: A=[0, 1, 1, 1, 1]  B=[1, 0, 0, 0, 0]
  trial 5: A=[1, 0, 0, 0, 0]  B=[0, 1, 1, 1, 1]
  trial 6: A=[1, 0, 1, 0, 0]  B=[0, 1, 0, 1, 1]
  trial 7: A=[0, 1, 0, 1, 1]  B=[1, 0, 1, 0, 0]

**Rationale:** To quantitatively dissociate the Advocated Theory (a Strategy Selection/Mixture model of TTB, Tallying, and WADD) from the Competing Theory (Sequential Evidence Accumulation with a stopping threshold), we exploit the fact that Sequential Accumulation only maintains a running sum of unweighted differences (+1 or -1) in validity order. If the threshold is 1, it acts exactly like Take-The-Best (TTB). If the threshold is high, it falls back to Pure Tallying. Consequently, if TTB and Tallying both agree on an option, Sequential Accumulation MUST choose that option, regardless of its threshold parameter. The Advocated Theory, however, includes WADD as a sub-model, which weights features by their log-odds validities. By selecting a specific set of validities (e.g., 0.95, 0.90, 0.85, 0.60, 0.55), we can construct trials where the single best feature (F1) and two weak features (F4, F5) support Option A, while two strong intermediate features (F2, F3) support Option B. In this scenario, TTB chooses A (wins F1) and Tallying chooses A (3 wins vs 2). Thus, the Competing Theory strictly predicts A. However, the log-odds sum for B (F2+F3) outweighs A (F1+F4+F5), meaning WADD chooses B. The Advocated Theory can therefore predict a substantial probability of choosing B, achieving a sharp qualitative and quantitative dissociation.

**Computed schedule:** 7 unique pairs × 13 reps = 91 trials per subject.



### METRIC
Rationale:
This metric calculates the proportion of times the subject chooses the option favored exclusively by the Weighted Additive (WADD) strategy in a specific pair of trials. Specifically, for the pair [1, 0, 0, 1, 1] vs. [0, 1, 1, 0, 0], both Take-The-Best and Tallying favor the first option. Furthermore, the Competing Theory's Sequential Accumulation mechanism also strictly prefers the first option, regardless of its threshold parameter (the accumulated evidence for the first option never drops below 0 and ends at +1). However, the WADD submodel in the Advocated Theory strongly favors the second option [0, 1, 1, 0, 0] because the combined log-odds of features 2 and 3 outweigh features 1, 4, and 5. Therefore, the Advocated Theory predicts a significantly higher choice rate for [0, 1, 1, 0, 0] than the Competing Theory, which will only choose it via random lapses.

**Rationale:** To quantitatively dissociate the Advocated Theory (Sequential Evidence Accumulation) from the Competing Theory (a Strategy Selection mixture of TTB, Tallying, and WADD), we exploit the Advocated Theory's unweighted accumulation and early stopping mechanism. By setting a specific sequence of validities, we can construct trials where the accumulated difference temporarily reaches a threshold (e.g., +2) favoring Option A, causing the Advocated Theory to stop early and choose A. However, by ensuring that Option B wins on the single most valid feature (so TTB chooses B), wins on a greater total number of features (so Tallying chooses B), and wins on the log-odds weighted sum of features (so WADD chooses B), the Competing Theory is structurally forced to predict a strict preference for B across all of its sub-models. This creates a stark qualitative and quantitative dissociation where the Advocated Theory can predict a choice that is literally impossible under the Competing Theory's framework.

**Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
By design, Option B wins the most valid cue in all trials, meaning Take-The-Best (and thus the Advocated Theory with a low threshold <= 1) always chooses B. However, for higher thresholds, the Advocated Theory's sequential accumulation can favor Option A. Specifically, a medium threshold (1 < thresh <= 2) triggers early stopping in Trial 1, leading to an Option A choice. A high threshold (thresh > 2) prevents early stopping in Trial 3, allowing the final tally to favor Option A, while still triggering early stopping for Option B in Trial 7. Thus, the Advocated Theory predicts that subjects with threshold > 1 will choose Option A in EITHER Trial 1 OR Trial 3, but not Trial 7. In contrast, the Competing Theory's sub-models either uniformly favor B (Trial 1) or have identical strategy mixtures for Trial 3 and Trial 7 (Tallying favors A, TTB/WADD favor B). Therefore, the metric `P(A|Trial 1) + P(A|Trial 3) - P(A|Trial 7)` will be near 0 for the Competing Theory (since P(A|T3) ≈ P(A|T7) and P(A|T1) ≈ 0), but will be strongly positive (~0.67) for the Advocated Theory, reliably discriminating the two models despite individual parameter differences.

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    
    a_ratings = np.array(data['option_a_ratings'].tolist())
    b_ratings = np.array(data['option_b_ratings'].tolist())
    
    a_wins = np.sum(a_ratings > b_ratings, axis=1)
    b_wins = np.sum(b_ratings > a_ratings, axis=1)
    
    valid_mask = a_wins != b_wins

        return 0.5

    responses = np.array(data['response'].tolist())
    
    matches = (responses[valid_mask] == tally_preds[valid_mask])
    return float(np.mean(matches))
