# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_20" and "pi_19") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_20" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_19" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_20
Non-linear Feature Difference Model with Flexible Validity Centering

def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    # Center validities with a flexible threshold rather than hardcoded 0.5
    theta = float(parameters["theta"])
    w = val - theta
    
    diff = a - b
    # Compute net evidence for option A over B
    net_ev = np.sum(w * diff)
    
    gamma = float(parameters["gamma"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Apply non-linear value function to the net evidence (Prospect Theory style)
    score = np.sign(net_ev) * (np.abs(net_ev) ** gamma)
    
    # Create scores for A and B
    scores = np.array([score, -score])
    
    # Softmax choice rule
    z = beta * scores
    z -= np.max(z) # For numerical stability
    e = np.exp(z)
    p_core = e / np.sum(e)
    
    return (1.0 - epsilon) * p_core + epsilon * np.array([0.5, 0.5])

    return np.random.choice(len(probabilities), p=probabilities)


## THEORY 2 — pi_19
Decision-makers use a dynamic sequential evidence accumulation process with a fixed absolute threshold. They evaluate features in decreasing order of validity, maintaining a running sum of the validity-weighted differences between options. After each feature, they compare the accumulated absolute evidence to a fixed threshold. If the evidence meets or exceeds this threshold, they stop and make a choice. This dynamically adapts the amount of information processed: highly conflicting early evidence keeps the accumulated difference near zero, prompting the integration of more features (similar to WADD or Tallying), whereas decisive early evidence leads to quick termination (similar to Take-The-Best).

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    # Order features by validity descending
    order = np.argsort(val)[::-1]
    
    threshold = float(parameters["threshold"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    e = 0.0
    for idx in order:
        e += val[idx] * (a[idx] - b[idx])
        
        # Dynamic stopping rule based on fixed absolute evidence threshold
        if abs(e) >= threshold and abs(e) > 0:
            break
            
    scores = np.array([e, -e])
    
    z = beta * scores
    z -= np.max(z)
    p_core = np.exp(z) / np.sum(np.exp(z))
    
    return (1.0 - epsilon) * p_core + epsilon * np.array([0.5, 0.5])

  trial 8: A=[0, 0, 1, 1, 1]  B=[1, 1, 0, 0, 0]

**Rationale:** To quantitatively dissociate the Advocated Theory (Non-linear Feature Difference Model with Flexible Validity Centering) from the Competing Theory (Sequential Evidence Accumulation), we exploit the fundamental difference between centering validities and accumulating raw uncentered validities. The Competing Theory sums raw validities, meaning every feature win adds positive evidence for that option. By constructing trials where the running tally reaches a high maximum but ends with a smaller value of the SAME sign (e.g., Diff = [1, -1, -1, 1, 1]), the Competing Theory is structurally forced to predict Option A regardless of its stopping threshold (since it either stops at F1 or finishes positive). In contrast, the Advocated Theory centers validities by a threshold 'theta'. For 'theta >= 0.5', the sum of centered validities for F2 and F3 easily outweighs F1, F4, and F5, predicting a robust preference for Option B. We also include trials that dissociate the effect of 'theta' within the Advocated Theory by making low-validity features act as negative evidence (penalizing the option that wins them).

**Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
This metric calculates the proportion of times the subject chooses the option with the top two features (F1, F2) over the option with the bottom three features (F3, F4, F5). Under the Advocated Theory, validity centering with theta > 0.15 makes the sum of centered validities for F1+F2 outweigh F3+F4+F5, strongly predicting a preference for the F1+F2 option. Under the Competing Theory, the sequential accumulation reaches a maximum early but ultimately falls to a negative final sum (-0.15) if the threshold is high enough (> 1.8), leading to a preference for the F3+F4+F5 option.

The Advocated Theory accumulates raw validities, which are always positive, meaning every feature win adds positive evidence for that option. By constructing trials where the running tally is strictly positive (or negative) at every step (e.g., Diff = [1, -1, 1, 1, 1]), the Advocated Theory is structurally forced to predict Option A regardless of its stopping threshold, as it either stops at F1 or finishes with a positive sum. ### METRIC
Rationale:
This metric calculates the proportion of trials where the subject chooses the option with features [1, 0, 1, 1, 1] over the option with [0, 1, 0, 0, 0]. For the Advocated Theory, the accumulated evidence for the first option is strictly positive at every single step of the sequential evaluation, meaning it will always predict choosing this option regardless of the stopping threshold. For the Competing Theory, the flexible validity centering allows the lower-validity features to receive negative weights if theta is sufficiently high (> 0.68), which penalizes the option with many lower-validity features and can lead to a robust preference for the [0, 1, 0, 0, 0] option. Thus, the Advocated Theory will predict a choice proportion near 1.0, while the Competing Theory will predict a significantly lower proportion.

def metric(data: pd.DataFrame) -> float:

    import pandas as pd

    b_tuples = data['option_b_ratings'].apply(tuple)

    t1_b = (0, 1, 0, 0, 0)

    is_t2 = (a_tuples == t1_b) & (b_tuples == t1_a)
    
    choices_t1 = data.loc[is_t1, 'response'] == 0
    choices_t2 = data.loc[is_t2, 'response'] == 1
    
    count = is_t1.sum() + is_t2.sum()
    if count == 0:
        return 0.5
        
    return float((choices_t1.sum() + choices_t2.sum()) / count)

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    import pandas as pd
    
    def is_tie(row):
        a = np.array(row['option_a_ratings'])
        b = np.array(row['option_b_ratings'])
        return np.sum(a > b) == np.sum(b > a)
        
    ties = data[data.apply(is_tie, axis=1)]
    if len(ties) == 0:
        return 0.0
        
    devs = []
    for subj, subj_df in ties.groupby('subject_id'):
        p_A = np.mean(subj_df['response'] == 0)
        devs.append(np.abs(p_A - 0.5))
        
    return float(np.mean(devs))

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    import pandas as pd

    diff_keys = []
    trial_keys = []
    for _, row in data.iterrows():
        a = tuple(row['option_a_ratings'])
        b = tuple(row['option_b_ratings'])
        diff_keys.append(tuple(x - y for x, y in zip(a, b)))
        trial_keys.append((a, b))
        
    data = data.assign(diff_key=diff_keys, trial_key=trial_keys)
    
    subj_diffs = []
    for subj, subj_df in data.groupby('subject_id'):
        trial_means = subj_df.groupby(['diff_key', 'trial_key'])['response'].mean().reset_index()
        
        diff_vars = []
        for diff_key, diff_df in trial_means.groupby('diff_key'):
            if len(diff_df) > 1:
                diff_vars.append(diff_df['response'].max() - diff_df['response'].min())
        
        if diff_vars:
            subj_diffs.append(np.mean(diff_vars))
            
    if not subj_diffs:
        return 0.0
    return float(np.mean(subj_diffs))
