# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_6" and "pi_9") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_6" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_9" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_6
People use a single-stage Additive Utility evaluation where features are weighted by a power-law transformation of their chance-centered objective validities. By avoiding artificial weight normalization and allowing for sufficiently high softmax temperatures and power parameters, the decision-making process can smoothly and stably interpolate between Tallying (equal weights), proportional weighting, and highly deterministic Take-The-Best behavior (where the most valid cues dominate completely).

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    
    val = np.asarray(parameters["validities"], dtype=float)
    gamma = float(parameters["gamma"])
    
    # Transform validities using a simple power law on chance-centered values
    # gamma=0 -> Tallying, gamma=1 -> WADD, gamma>1 -> TTB
    centered_val = val - 0.5
    weights = (centered_val + 1e-6) ** gamma
    
    scores = np.array([np.sum(a * weights), np.sum(b * weights)])
    
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Softmax with max-subtraction for numerical stability
    z = beta * (scores - np.max(scores))
    e = np.exp(z)
    p_core = e / np.sum(e)
    
    n_opts = p_core.shape[0]
    return (1.0 - epsilon) * p_core + epsilon * (np.ones(n_opts) / n_opts)

def policy(probabilities):

    probabilities = np.asarray(probabilities, dtype=np.float64)
    probabilities /= probabilities.sum()
    return np.random.choice(len(probabilities), p=probabilities)


## THEORY 2 — pi_9
Decision-makers use a Sequential Evidence Accumulation strategy with a stopping rule. They inspect features one by one in descending order of their validity, maintaining a running sum of the differences between the options. If the absolute accumulated evidence reaches or exceeds a specific threshold, they stop and make a choice based on that evidence. If the threshold is not reached, they evaluate all features and decide based on the final tally. This allows the model to smoothly transition between Take-The-Best (low threshold) and Tallying (high threshold) behaviors.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f"Expected a (2, n_features) stimulus; got shape {stim.shape}.")
        
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    # Order features by validity descending
    order = np.argsort(val)[::-1]
    
    threshold = float(parameters["threshold"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    diff = a - b
    accumulated_evidence = 0.0
    
    for idx in order:
        accumulated_evidence += diff[idx]
        if abs(accumulated_evidence) >= threshold and abs(accumulated_evidence) > 0:
            break
            
    scores = np.array([accumulated_evidence, -accumulated_evidence])
    
    z = beta * scores
    z -= np.max(z)
    p_core = np.exp(z) / np.sum(np.exp(z))
    
    return (1.0 - epsilon) * p_core + epsilon * np.array([0.5, 0.5])

## EXPERIMENT 1 (proposed by pi_6)

### DESIGN
**Validities (n_features=5):** [0.95, 0.85, 0.75, 0.65, 0.55]

**Trial pairs (n=6):**
  trial 1: A=[1, 0, 1, 0, 0]  B=[0, 1, 0, 1, 0]
  trial 2: A=[0, 1, 1, 1, 0]  B=[1, 0, 0, 0, 0]
  trial 3: A=[1, 0, 0, 0, 1]  B=[0, 1, 1, 0, 0]
  trial 4: A=[0, 1, 0, 1, 1]  B=[1, 0, 0, 0, 0]
  trial 5: A=[1, 0, 0, 1, 0]  B=[0, 1, 1, 0, 0]
  trial 6: A=[0, 1, 1, 0, 0]  B=[1, 0, 0, 1, 1]

**Rationale:** This design quantitatively dissociates the Advocated Theory (Additive Utility with power-law validity weighting) from the Competing Theory (Sequential Evidence Accumulation with a stopping threshold) by exploiting how they handle conflicting evidence across multiple features. The Competing Theory accumulates raw binary differences (+1 or -1) and either stops early (acting like pure Take-The-Best if threshold <= 1) or proceeds to the end, falling back on a pure feature tally. In contrast, the Advocated Theory continuously scales feature differences by a power-law transformation of their validities. By constructing trials where the running tally drops back to zero before the final feature, we create cases where the Competing Theory is forced to guess if its threshold is greater than 1, while the Advocated Theory predicts a deterministic preference due to the asymmetric validities of the features involved. Pitting these against trials where a high threshold is required to choose the option with more feature wins creates a logical contradiction for the Competing Theory, as it cannot simultaneously hold a low and high threshold to match the smoothly interpolated compensatory choices predicted by the Advocated Theory.

**Computed schedule:** 6 unique pairs × 16 reps = 96 trials per subject.



### METRIC
Rationale:
This metric calculates 2 * P(A|T3) + P(A|T4). Under the Competing Theory (Sequential Evidence Accumulation), this linear combination is a theoretical invariant. For low thresholds (<=1), SEA stops at the first feature, yielding P(A|T3)=1 and P(A|T4)=0, so the sum is 2. For high thresholds (>1), SEA evaluates to the end for T3 (yielding a tie, P=0.5) and strictly prefers A for T4 (P=1), again yielding 2 * 0.5 + 1 = 2. Thus, SEA predicts a constant value of ~1.9 (after epsilon adjustments) with near-zero parameter variance. In contrast, the Advocated Theory (Additive Utility) applies compensatory weighting. For most of its parameter space (gamma > 1), the weights of less valid features decay rapidly, pushing both choice probabilities towards 0.5, which bounds this metric around 1.5. For gamma=1, T3 yields a negative score and T4 a positive score, dropping the metric even lower (towards 1.0). Therefore, the Advocated Theory predicts a significantly lower and tightly bounded value (~1.5) than SEA (~1.9), providing a massive mean gap with exceptionally low between-subject variance for reliable discrimination.

## EXPERIMENT 2 (proposed by pi_9)

### DESIGN
**Validities (n_features=5):** [0.95, 0.9, 0.85, 0.7, 0.6]

**Trial pairs (n=4):**
  trial 1: A=[1, 0, 0, 0, 1]  B=[0, 1, 1, 0, 0]
  trial 2: A=[0, 1, 1, 1, 0]  B=[1, 0, 0, 0, 1]
  trial 3: A=[1, 0, 1, 0, 0]  B=[0, 1, 0, 1, 1]
  trial 4: A=[0, 0, 1, 1, 1]  B=[1, 1, 0, 0, 0]

**Rationale:** To quantitatively dissociate the Advocated Theory (Sequential Evidence Accumulation) from the Competing Theory (Additive Utility with power-law validities), we exploit how the Advocated Theory accumulates *unweighted* evidence differences. Because the Advocated Theory merely counts +1 or -1 in validity order, it can never differentiate between the magnitudes of features once the order is set, except by stopping early. By constructing trials where the running tally of differences fluctuates but never reaches a high threshold, we force the Advocated Theory to either guess (if it reaches the end with a tie) or choose the Take-The-Best option (if the threshold is low). In contrast, the Competing Theory weights features by their chance-centered validities, allowing combinations of slightly less valid features to overpower the single best feature, predicting a strong preference for an option that the Advocated Theory can literally never choose under any parameterization.

**Computed schedule:** 4 unique pairs × 24 reps = 96 trials per subject.



### METRIC
Rationale:
Calculates the sum of the probability of choosing Option A in Trial 2 and Trial 3. Under the Advocated Theory (Sequential Evidence Accumulation), a threshold <= 1 leads to choosing B in T2 and A in T3, while a threshold > 1 leads to choosing A in T2 and B in T3. Thus, for any threshold, the expected sum of P(A|T2) + P(A|T3) is exactly 1.0, resulting in extremely low between-subject variance. Under the Competing Theory (Additive Utility), moderate values of gamma (e.g., gamma around 1 to 3) lead to choosing A in both T2 and T3 due to the power-law weighting of cues, pushing the sum significantly higher than 1.0. This creates a large mean difference and exploits the structural invariance in the Advocated Theory to guarantee a highly significant Welch's t-test.

    import numpy as np
    
    val = np.array([0.95, 0.7, 0.65, 0.6, 0.55])
    w = val - 0.5
    
    match_count = 0
    total = 0
    
    for _, row in data.iterrows():
        a = np.array(row['option_a_ratings'])
        b = np.array(row['option_b_ratings'])

            score_b = np.sum(b * w)

                target = 0
            elif score_b > score_a:
                target = 1
            else:
                continue
                
            if row['response'] == target:
                match_count += 1
            total += 1
            
    if total == 0:
        return 0.5
        
    return match_count / total

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    import pandas as pd
    
    def is_tie(row):
        a = np.array(row['option_a_ratings'])
        b = np.array(row['option_b_ratings'])
        return np.sum(a > b) == np.sum(b > a)
        
    ties = data[data.apply(is_tie, axis=1)]
    if len(ties) == 0:
        return 0.0
        
    devs = []
    for subj, subj_df in ties.groupby('subject_id'):
        p_A = np.mean(subj_df['response'] == 0)
        devs.append(np.abs(p_A - 0.5))
        
    return float(np.mean(devs))
