# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_16" and "pi_17") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_16" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_17" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_16
Leaky Competing Accumulator with Non-linear Configural Weighting and Evidence Transduction: Decision-makers evaluate cues simultaneously, with evidence for each option dynamically inhibiting the other in a leaky competing accumulator (LCA). Cues have a configural impact, scaled non-linearly by the total number of supporting cues. Additionally, the integrated evidence for each option is passed through a non-linear transducer (alpha) before entering the accumulation process, allowing the model to amplify the differences driven by high-validity cues and capture strong non-compensatory reversals.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, stimulus, history):
    import numpy as np
    
    stim = np.asarray(stimulus, dtype=float)
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    gamma = float(parameters["gamma"])
    leak = float(parameters["leak"])
    inhibition = float(parameters["inhibition"])
    theta = float(parameters["theta"])
    epsilon = float(parameters["epsilon"])
    alpha = float(parameters["alpha"])
    
    sum_a = np.sum(a)
    sum_b = np.sum(b)
    
    # Configural weighting: effective validity of a cue is non-linearly modulated by the total number of cues
    # Using max(1e-6, sum) to avoid 0^negative_gamma undefined errors
    sum_a_safe = max(1e-6, sum_a)
    sum_b_safe = max(1e-6, sum_b)
    
    w_a = val * (sum_a_safe ** gamma)
    w_b = val * (sum_b_safe ** gamma)
    
    # Make sure inputs are non-negative and apply non-linear transducer alpha
    I_A = max(0.0, np.sum(w_a * a)) ** alpha
    I_B = max(0.0, np.sum(w_b * b)) ** alpha
    
    # Leaky Competing Accumulator (LCA) simulation
    x_a, x_b = 0.0, 0.0
    dt = 0.1
    steps = 100
    
    for _ in range(steps):
        dx_a = (I_A - leak * x_a - inhibition * x_b) * dt
        dx_b = (I_B - leak * x_b - inhibition * x_a) * dt
        
        x_a = max(0.0, x_a + dx_a)
        x_b = max(0.0, x_b + dx_b)
        
    # Softmax choice based on final activations
    z = theta * np.array([x_a, x_b])
    z = z - np.max(z)
    e = np.exp(z)
    p = e / np.sum(e)
    
    return (1.0 - epsilon) * p + epsilon * np.array([0.5, 0.5])

def policy(probabilities):

    probabilities /= probabilities.sum()
    return np.random.choice(len(probabilities), p=probabilities)


## THEORY 2 — pi_17
Sequential Evidence Accumulation with Dynamic Stopping Rule (SPRT Log-Odds Update)

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, stimulus, history):
    import numpy as np
    
    stim = np.asarray(stimulus, dtype=float)
    a, b = stim[0], stim[1]
    val = np.asarray(parameters["validities"], dtype=float)
    
    threshold = float(parameters["threshold"])
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Process cues sequentially, ordered by validity (descending)
    cue_order = np.argsort(-val, kind="stable").tolist()
    
    diff_evidence = 0.0
    for j in cue_order:
        # Evidence weight for the current cue using SPRT log-odds
        v = np.clip(val[j], 1e-5, 1.0 - 1e-5)
        weight = np.log(v / (1.0 - v))
        
        if a[j] > b[j]:
            diff_evidence += weight
        elif b[j] > a[j]:
            diff_evidence -= weight
            
        # Dynamic stopping rule: stop search if evidence difference exceeds threshold
        if abs(diff_evidence) >= threshold:
            break
            
    # Map accumulated evidence to choice probabilities using softmax
    # diff_evidence represents the relative evidence of A over B
    z = np.array([beta * diff_evidence, 0.0])
    z = z - np.max(z)
    e = np.exp(z)
    p = e / np.sum(e)
    
    # Apply lapse rate
    return (1.0 - epsilon) * p + epsilon * np.array([0.5, 0.5])

**Rationale:** This design quantitatively dissociates the advocated LCA model with Configural Weighting from the competing Sequential Evidence Accumulation (SPRT) theory by exploiting their divergent treatment of tied cues. The competing theory processes cues sequentially based on validity and calculates log-odds evidence differences; crucially, it completely ignores any cue that is tied (where both options have a 1), meaning its choice predictions remain exactly identical regardless of how many tied cues are added. The advocated theory, however, utilizes a configural weighting mechanism where the effective weight of every cue is non-linearly scaled by the total number of cues favoring that option. By presenting base trials with a fixed set of discriminating cues and systematically adding tied cues (1s for both options) to the remaining features, the competing theory predicts perfectly flat, invariant choice probabilities across each set. The advocated theory predicts systematic, graded shifts in choice probabilities as the increasing total cue counts modulate the configural weights of the discriminating cues.

**Computed schedule:** 14 unique pairs × 6 reps = 84 trials per subject.



### METRIC
Rationale:
This metric exploits a structural divergence between LCA's linear summation of validities and SPRT's sequential log-odds updating. In Trials 13 and 14, the linear sum of validities for Option A and Option B are exactly equal, and their total cue counts are also equal. Because LCA evaluates evidence by linearly summing validities (modulated by total cue count) before its non-linear transducer, it predicts a choice probability of EXACTLY 0.5 for these trials, regardless of its parameter values. SPRT, however, processes cues sequentially using log-odds. Because the most valid cue favors Option A, and the sum of the non-linear log-odds yields a net positive evidence for A (+0.731), SPRT consistently predicts a high choice probability for A (>0.5). By subtracting the choice rate of Trials 13-14 from the choice rate of Trials 1-12 (where both models strongly favor A), we get a metric that is near 0 for SPRT (since it strongly favors A in both sets) but strongly positive (~0.35) for LCA (since it drops to exactly 0.5 in the latter set). Filtering for equal total cue counts across these sets completely neutralizes the between-subject variance from LCA's configural gamma parameter, ensuring extremely tight within-theory predictions.

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    import pandas as pd
    
    val = np.array([0.95, 0.85, 0.75, 0.65, 0.55])
    scores = []
    
    for subj, subj_df in data.groupby('subject_id'):
        high_choices = []
        mid_choices = []
        
        for _, row in subj_df.iterrows():
            a = np.array(row['option_a_ratings'])
            b = np.array(row['option_b_ratings'])
            
            sum_a = np.sum(a)
            sum_b = np.sum(b)
            
            # Only look at trials where both options have the same total number of cues.
            # This perfectly neutralizes the variance caused by LCA's configural gamma parameter.
            if sum_a == sum_b:
                val_a = np.sum(a * val)
                val_b = np.sum(b * val)
                
                chose_a = 1.0 if row['response'] == 0 else 0.0
                
                # Trials 1-4 and 9-12: The linear sum of validities strongly favors A.
                if val_a > val_b + 1e-4:
                    high_choices.append(chose_a)
                # Trials 13-14: The linear sum of validities is EXACTLY equal for A and B.
                elif abs(val_a - val_b) <= 1e-4:
                    mid_choices.append(chose_a)
                    
        if len(high_choices) > 0 and len(mid_choices) > 0:
            scores.append(np.mean(high_choices) - np.mean(mid_choices))
            
    if not scores:
        return 0.0
        
    return float(np.mean(scores))

**Rationale:** This design quantitatively dissociates the advocated Sequential Evidence Accumulation (SPRT) theory from the competing Leaky Competing Accumulator (LCA) theory by neutralizing LCA's configural weighting and exploiting the extreme non-linearity of SPRT's log-odds update. The LCA model configurally scales the weight of each cue by the total number of cues favoring that option (sum ** gamma). By strictly matching the total number of positive cues for both options on every critical trial (sum_a == sum_b), we completely neutralize this configural effect, reducing LCA to a linear integrator of raw validities (passed through a transducer). SPRT, however, accumulates evidence using log-odds (log(v / (1 - v))), which becomes extremely non-linear for high validities. By pitting a single very high validity cue (e.g., 0.95, which has a massive log-odds weight) accompanied by weak cues against multiple moderate validity cues (e.g., 0.80, 0.75), LCA predicts that the sum of the moderate raw validities will easily outweigh the top cue. SPRT predicts the exact opposite: the massive log-odds weight of the top cue will dominate the accumulation, leading to a strict preference for the option with the single best cue, regardless of the raw validity sum.

**Computed schedule:** 6 unique pairs × 16 reps = 96 trials per subject.



### METRIC
Rationale:
This metric calculates the proportion of times Option A is chosen on critical trials where Option A has the highest validity cue (cue 1) but Option B has multiple moderate validity cues (cues 2 and 3). Under the advocated SPRT theory, the massive log-odds weight of the top cue dominates the sequential accumulation process, often triggering an early decision in favor of A. Under the competing LCA theory, the configural weighting is neutralized by the design, and the linear sum of the raw validities for B's moderate cues often exceeds or matches A's single top cue, leading to a much lower rate of choosing A.

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    
    def get_ttb_winner(a, b):
        for i in range(len(a)):
            if a[i] > b[i]: return 0
            if b[i] > a[i]: return 1
        return -1

    extreme_comp = []
    extreme_noncomp = []
    
    for _, row in data.iterrows():
        a = row['option_a_ratings']
        b = row['option_b_ratings']
        resp = row['response']
        
        ttb_win = get_ttb_winner(a, b)
        if ttb_win == -1:
            continue
            
        ttb_chosen = 1 if resp == ttb_win else 0
        
        # Tallying margin for the TTB winner
        margin = sum(a) - sum(b) if ttb_win == 0 else sum(b) - sum(a)
            
        # Extreme compensatory trials (TTB winner is opposed by many cues)
        if margin <= -2:
            extreme_comp.append(ttb_chosen)
        # Non-compensatory trials (TTB winner is supported by overall cue sum)
        elif margin >= 1:
            extreme_noncomp.append(ttb_chosen)
            
    if not extreme_comp or not extreme_noncomp:
        return 0.0
        
    return float(np.mean(extreme_noncomp) - np.mean(extreme_comp))

    def get_first_diff(row):
        a = row['option_a_ratings']
        b = row['option_b_ratings']
        for i, (val_a, val_b) in enumerate(zip(a, b)):
            if val_a != val_b:
                return i
        return -1

    # Calculate which cue is the highest valid discriminating cue
    first_diffs = data.apply(get_first_diff, axis=1)
    
    # Probability of choosing Option A
    chose_a = 1 - data['response']
    
    # Mean P(Choose A) when Cue 1 (index 0) is the highest discriminating cue

    a = np.array(data['option_a_ratings'].tolist())
    b = np.array(data['option_b_ratings'].tolist())
    resp = data['response'].values
    
    sum_a = a.sum(axis=1)
    sum_b = b.sum(axis=1)

    hvo_chosen = np.sum((cond_a & (resp == 0)) | (cond_b & (resp == 1)))
    total = np.sum(cond_a | cond_b)
