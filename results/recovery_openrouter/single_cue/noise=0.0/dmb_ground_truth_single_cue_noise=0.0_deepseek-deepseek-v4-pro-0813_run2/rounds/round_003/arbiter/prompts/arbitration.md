# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_5" and "pi_4") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_5" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_4" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_5
People compare options through a conflict-gated dual-lexicographic/tallying system. A baseline mixture combines a weak forward Take-The-Best route, a moderate backward lexicographic route, and feature-win tallying. When the highest-validity and lowest-validity cues discriminate in opposite directions and the tally does not oppose the highest cue, the decision maker enters a conflict regime: tallying is suspended and the choice is made with high probability by a strong backward lexicographic scan over ascending validities. Subjects differ substantially in how strongly and deterministically they reverse on such conflict trials.

def predict(parameters, state, history):
    import numpy as np

    stim = np.asarray(state, dtype=float)
    if stim.ndim == 3 and stim.shape[0] == 1:
        stim = stim[0]
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(f'Expected a (2, n_features) stimulus, got {stim.shape}.')

    a = stim[0]
    b = stim[1]
    n_features = stim.shape[1]

    validities = parameters.get('validities')
    if validities is None:
        validities = list(np.linspace(0.9, 0.5, n_features))
    validities = np.asarray(validities, dtype=float)
    if validities.ndim == 0 or validities.shape[0] != n_features:
        validities = np.linspace(0.9, 0.5, n_features)

    descending = np.argsort(-validities, kind='stable')
    ascending = np.argsort(validities, kind='stable')

    def lex_probabilities(order, beta):
        winner = None
        for j in order:
            if a[j] > b[j]:
                winner = 0
                break
            if b[j] > a[j]:
                winner = 1
                break
        if winner is None:
            return np.ones(2, dtype=float) / 2.0
        z = float(beta) if winner == 0 else -float(beta)
        p_a = 1.0 / (1.0 + np.exp(-z))
        return np.array([p_a, 1.0 - p_a], dtype=float)

    beta_forward = float(parameters['beta_forward'])
    beta_backward = float(parameters['beta_backward'])
    beta_conflict_backward = float(parameters['beta_conflict_back'])

    p_forward = lex_probabilities(descending, beta_forward)
    p_backward_base = lex_probabilities(ascending, beta_backward)
    p_backward_conflict = lex_probabilities(ascending, beta_conflict_backward)

    a_wins = float(np.sum(a > b))
    b_wins = float(np.sum(b > a))
    tally_scores = np.array([a_wins, b_wins], dtype=float)
    beta_tally = float(parameters['beta_tally'])
    z = beta_tally * (tally_scores - np.max(tally_scores))
    e = np.exp(z)
    p_tally = e / np.sum(e)

    w_forward_base = float(parameters['w_forward'])
    w_backward_base = float(parameters['w_backward'])
    w_tally_base = 1.0 - w_forward_base - w_backward_base
    if w_tally_base < 0.0:
        w_tally_base = 0.0
        denom = w_forward_base + w_backward_base
        w_forward_base /= denom
        w_backward_base /= denom

    j_hi = descending[0]
    j_lo = ascending[0]
    hi_dir = 0 if a[j_hi] == b[j_hi] else (1 if a[j_hi] > b[j_hi] else -1)
    lo_dir = 0 if a[j_lo] == b[j_lo] else (1 if a[j_lo] > b[j_lo] else -1)
    tally_d = int(a_wins - b_wins)

    extreme_cue_conflict = (hi_dir != 0 and lo_dir != 0 and hi_dir == -lo_dir)
    live_conflict = extreme_cue_conflict and (tally_d * hi_dir >= 0)

    if live_conflict:
        w_forward = 1.0 - float(parameters['w_conflict_back'])
        w_backward = float(parameters['w_conflict_back'])
        w_tally = 0.0
        p_backward = p_backward_conflict
    else:
        w_forward = w_forward_base
        w_backward = w_backward_base
        w_tally = w_tally_base
        p_backward = p_backward_base

    weights = np.array([w_forward, w_backward, w_tally], dtype=float)
    weights = weights / weights.sum()

    p = weights[0] * p_forward + weights[1] * p_backward + weights[2] * p_tally

    epsilon = float(parameters.get('epsilon', 0.0))
    if epsilon > 0.0:
        p = (1.0 - epsilon) * p + epsilon * np.ones(2, dtype=float) / 2.0

    p = np.clip(p, 0.0, None)
    return p / p.sum()

def policy(probs):
    import numpy as np
    probs = np.asarray(probs, dtype=float)
    probs = probs / probs.sum()
    return int(np.random.choice(len(probs), p=probs))


## THEORY 2 — pi_4
People choose between two options through a stable, subject-level mixture of three comparison routes: (1) forward lexicographic scanning, inspecting cues in descending validity order and stopping at the first discriminating cue; (2) backward lexicographic scanning, inspecting cues in ascending validity order and stopping at the first discriminating cue in that reversed order; and (3) feature-win tallying, where each option receives one point per feature on which it strictly beats the other and ties contribute nothing. The forward and backward lexicographic weights jointly act as a subject-level polarity parameter for first-validity-cue effects: forward weight supports a positive first-discriminator effect, while backward weight supports a negative one. Each route's preferred option is passed through its own softmax choice rule, so responding is noisy but not controlled by a uniform lapse.

**Rationale:** This design isolates the conflict-gate discontinuity that separates the advocated model from the stable-mixture model. Six experts have validities [0.90, 0.80, 0.70, 0.60, 0.55, 0.52]; feature 0 is the highest-validity cue and feature 5 is the lowest. On every trial these two cues discriminate in opposite directions (top-A/low-B or top-B/low-A). The four middle cues set the feature-win tally difference d = A_wins - B_wins to -2, -1, 0, +1, +2, with both signs present in both top-cue directions. For top-A/low-B trials the advocated model enters its conflict regime whenever d >= 0: tallying is suspended and the backward scan is boosted, so P(A) drops to about 0.15 and stays flat across d = 0, +1, +2. The competing stable mixture instead predicts a smooth monotonic increase from about 0.24 at d = -2 to about 0.48 at d = +2. For top-B/low-A trials the advocated conflict regime is active for d <= 0, giving P(A) near 0.85 for d = -2, -1, 0, whereas the competing model predicts only about 0.52-0.64. The non-conflict cells (top-A d < 0 and top-B d > 0) serve as controls where the two models nearly coincide. This drop/inversion at d = 0 for top-A trials and high plateau for top-B trials cannot be produced by any stable mixture of forward, backward, and tally routes, because that model is smooth and monotonic in d. The 32 unique pairs are balanced over top direction and d and repeated K = 3 for 96 total trials.

**Computed schedule:** 32 unique pairs × 3 reps = 96 trials per subject.



### METRIC
Rationale:
This metric recodes every trial relative to the option favored by the highest-validity cue (feature 0) and measures the proportion of top-cue choices on conflict-gate trials, defined as rows where the top-cue option does not trail the opposite option in the feature-win tally (top_wins - other_wins >= 0). The advocated conflict-gated model suspends tallying in these rows and boosts a strong backward/low-cue route, predicting a low and flat top-cue choice rate around 0.17. The competing stable mixture keeps all three routes active, so its top-cue choice rate increases with the tally and averages around 0.43 on the same rows. Because each subject contributes many such rows, the per-subject estimate is stable while the model separation is large.

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    choices = []
    for _, row in data.iterrows():
        a = [int(x) for x in row['option_a_ratings']]
        b = [int(x) for x in row['option_b_ratings']]
        if a[0] == b[0]:
            continue
        top = 0 if a[0] > b[0] else 1
        top_vec = a if top == 0 else b
        other_vec = b if top == 0 else a
        d_top = 0
        for i in range(len(top_vec)):
            if top_vec[i] > other_vec[i]:
                d_top += 1
            elif other_vec[i] > top_vec[i]:
                d_top -= 1
        if d_top >= 0:
            choices.append(1.0 if int(row['response']) == top else 0.0)
    if not choices:
        return 0.5
    return float(np.mean(choices))

In matched gate-inactive trials, feature 0 is tied and feature 1—the other tied-highest cue—discriminates in the same top direction. For the advocated stable mixture, each matched pair is identical: forward lexicographic stops at the same top-direction winner (feature 0 or feature 1), backward lexicographic stops at feature 7, and the tally difference d is held constant by adjusting feature 2. The advocated model therefore predicts exactly equal P(A) for matched gate-active and gate-inactive trials. The competing model instead predicts a large gate-condition gap: on gate-active trials tallying is suspended and a strong backward scan dominates, whereas on gate-inactive trials the baseline tally route remains active. ### METRIC
Rationale:
Score every trial as 1 if the response selected the option favored by the lowest-validity cue (feature 7), otherwise 0. The metric is the mean score on conflict-gate-active trials minus the mean score on the remaining inactive trials. The advocated stable mixture predicts identical choice probabilities for matched active and inactive trials because the forward winner, backward winner, and tally difference are matched, so this contrast is expected to be near zero with only binomial noise. The competing conflict-gated model predicts a large positive contrast because active conflict trials suspend tallying and strongly use a backward scan that stops at feature 7. With 48 active and 48 inactive trials per subject, the within-subject variability is small.

import numpy as np
import pandas as pd

def metric(data: pd.DataFrame) -> float:
    if data.empty:
        return 0.0
    validities = np.array([0.9, 0.9, 0.8, 0.7, 0.6, 0.55, 0.52, 0.5], dtype=float)
    j_hi = int(np.argmax(validities))
    j_lo = int(np.argmin(validities))

    a_arr = np.array([np.asarray(x, dtype=float) for x in data['option_a_ratings']])
    b_arr = np.array([np.asarray(x, dtype=float) for x in data['option_b_ratings']])
    resp = np.asarray(data['response'], dtype=float)

    hi_diff = a_arr[:, j_hi] - b_arr[:, j_hi]
    lo_diff = a_arr[:, j_lo] - b_arr[:, j_lo]
    d = (a_arr > b_arr).sum(axis=1) - (b_arr > a_arr).sum(axis=1)

    hi_dir = np.where(hi_diff > 0, 1, np.where(hi_diff < 0, -1, 0))
    lo_dir = np.where(lo_diff > 0, 1, np.where(lo_diff < 0, -1, 0))
    live = (hi_dir != 0) & (lo_dir != 0) & (hi_dir == -lo_dir) & (d * hi_dir >= 0)

    y = np.where(lo_dir > 0, (resp == 0).astype(float),
                 np.where(lo_dir < 0, (resp == 1).astype(float), 0.5))

def metric(data: pd.DataFrame) -> float:
    scores = []
    for _, row in data.iterrows():
        a = np.asarray(row["option_a_ratings"], dtype=float)
        b = np.asarray(row["option_b_ratings"], dtype=float)

        response_a = 1.0 if int(row["response"]) == 0 else 0.0

        # Take The Best style second-cue prediction.
        # By design, feature 0 is tied on every trial, so feature 1 is
        # the first discriminating cue.
        if a[1] > b[1]:
            second_wins_a = True
        elif b[1] > a[1]:
            second_wins_a = False
        else:
            second_wins_a = True

        second_score = response_a if second_wins_a else (1.0 - response_a)

        # Tallying total score. Feature-specific ties contribute zero.
        wins_a = float(np.sum(a > b))
        wins_b = float(np.sum(b > a))
        tally_d = wins_a - wins_b

        if tally_d > 0.0:
            tally_score = response_a
        elif tally_d < 0.0:
            tally_score = 1.0 - response_a
        else:
            # Tallying has no preference on a tied tally.
            tally_score = 0.5

        scores.append(tally_score - second_score)

    return float(np.mean(scores)) if scores else 0.0

def metric(data: pd.DataFrame) -> float:
    validities = np.array([0.92, 0.88, 0.80, 0.72, 0.65, 0.60, 0.55, 0.52])

    pos = []
    neg = []

        b = np.asarray(row.option_b_ratings, dtype=float)
        first = 'A'
        found = False

            if a[j] > b[j]:
                first = 'A'

        if first == 'A':
            pos.append(chose_a)
        else:
            neg.append(chose_a)

        return 0.0
    return float(np.mean(pos) - np.mean(neg))
