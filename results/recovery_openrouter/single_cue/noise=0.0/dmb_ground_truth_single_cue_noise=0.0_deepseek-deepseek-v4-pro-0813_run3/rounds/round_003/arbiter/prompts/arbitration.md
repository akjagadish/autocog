# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Decision Making (Binary Features) domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_3" and "pi_5") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_3" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_5" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of binary expert ratings (each 0 or 1). Every experiment fixes its own feature count (via `validities` length) and per-expert validities; both are LLM-proposed. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_3
People use a validity-graded compensatory integration rule. On every choice they inspect all features, compute a signed option advantage by summing each discriminating feature's contribution, and then choose via a softmax over that advantage plus an independent lapse. Unlike Take The Best there is no early stopping. Unlike pure Tallying, each feature's contribution is weighted by a validity-sensitive multiplier. The multiplier is anchored around equal weighting, w_j = 1 + kappa * (v_j - mean(v)), normalized so the average weight is exactly 1. Because kappa has a symmetric prior centered at zero, the population-level expected weight vector is the equal-weight vector, but individual subjects may slightly overweight or underweight higher-validity cues. Tied features contribute nothing.

`predict(parameters, state, history) -> np.ndarray`:
import numpy as np

def predict(parameters, state, history):
    # Validity-graded compensatory integration.
    # state is the current pair of option feature vectors, shape (2, n_features).
    # Row 0 = option A, row 1 = option B. History is irrelevant because there is
    # no trial-by-trial feedback and the rule is applied independently each trial.
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError(
            f"Validity-graded integration expects a (2, n_features) stimulus; got shape {stim.shape}."
        )

    validities = np.asarray(parameters["validities"], dtype=float)
    n_features = stim.shape[1]
    if validities.shape[0] != n_features:
        raise ValueError(
            f"validities length {validities.shape[0]} != n_features {n_features}."
        )

    # Validity-sensitive weights around a strict equal-weight anchor.
    # The centered validities sum to zero, so the raw weights sum to n_features.
    # Normalizing by their mean keeps the scale of the advantage score directly
    # comparable to an unweighted signed tally when kappa is small.
    kappa = float(parameters["kappa"])
    centered_validities = validities - np.mean(validities)
    weights = 1.0 + kappa * centered_validities
    weights = weights / np.mean(weights)

    # Discriminating features contribute according to their weights; ties
    # have difference zero and thus contribute nothing.
    advantage = float(np.dot(weights, stim[0] - stim[1]))

    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])

    # Stable softmax over the signed advantage versus a zero-advantage boundary.
    # This reduces to logistic choice in the weighted advantage.
    scores = np.array([advantage, 0.0])
    z = beta * (scores - np.max(scores))
    e = np.exp(z)
    p_core = e / np.sum(e)

    n_opts = 2
    return (1.0 - epsilon) * p_core + epsilon * (np.ones(n_opts) / n_opts)

## THEORY 2 — pi_5
People adaptively decide whether unweighted tallying is diagnostic in the current task. They monitor two context signals over recent stimulus history: the prevalence of tally ties and the mean absolute per-trial validity-weighted evidence on those tie trials. When ties are rare, choice remains essentially unweighted tallying. When ties are prevalent and validity evidence is diagnostically substantial in absolute magnitude on tie trials, a validity-based tie-break policy is recruited. The recruitment is near-binary rather than continuous, so low-tie tasks recover near-tallying behavior while high-tie diagnostic tasks show strong validity-aligned tie-breaking. Unlike a fixed validity-gated tallying rule, the validity route is switched by task composition, and unlike continuous validity grading, validity is not mixed into every trial.

import numpy as np


def predict(parameters, state, history):
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError('Context-gated tallying expects a (2, n_features) stimulus; got shape %s.' % (stim.shape,))

    validities = np.asarray(parameters['validities'], dtype=float)
    n_features = stim.shape[1]
    if validities.shape[0] != n_features:
        raise ValueError('validities length %d != n_features %d.' % (validities.shape[0], n_features))

    a = stim[0]
    b = stim[1]
    diff = a - b

    wins_a = float(np.sum(a > b))
    wins_b = float(np.sum(b > a))
    tally_d = wins_a - wins_b

    tau_tie = float(parameters['tau_tie'])

    h_a = history.get('option_a_ratings', [])
    h_b = history.get('option_b_ratings', [])
    n_past = min(len(h_a), len(h_b))

    window = int(round(float(parameters['history_window'])))
    if window < 1:
        window = 1
    start = max(0, n_past - window)

    lin_weights = validities - 0.5
    tie_count = 0.0
    abs_evidence_sum = 0.0

    for i in range(start, n_past):
        pa = np.asarray(h_a[i], dtype=float)
        pb = np.asarray(h_b[i], dtype=float)
        past_wins = float(np.sum(pa > pb)) - float(np.sum(pb > pa))
        if abs(past_wins) <= tau_tie:
            tie_count += 1.0
            v_lin = float(np.dot(lin_weights, pa - pb))
            abs_evidence_sum += abs(v_lin)

    current_tie = 1.0 if abs(tally_d) <= tau_tie else 0.0
    tie_count += current_tie
    if current_tie:
        v_lin_current = float(np.dot(lin_weights, diff))
        abs_evidence_sum += abs(v_lin_current)

    total_considered = min(n_past, window) + 1.0
    c = tie_count / total_considered if total_considered > 0.0 else 0.0

    mean_abs_evidence = abs_evidence_sum / max(tie_count, 1.0)

    c0 = float(parameters['c0'])
    gate_width = float(parameters['gate_width'])
    ctx_power = float(parameters['ctx_power'])
    lambda_min = float(parameters['lambda_min'])
    lambda_max = float(parameters['lambda_max'])
    consistency_floor = float(parameters['consistency_floor'])
    min_cons_ties = int(parameters['min_cons_ties'])

    g = float(np.clip((c - c0) / max(gate_width, 1e-12), 0.0, 1.0))

    if tie_count >= min_cons_ties and mean_abs_evidence >= consistency_floor:
        veto = 1.0
    else:
        veto = 0.0

    lamb = lambda_min + (lambda_max - lambda_min) * (g ** ctx_power) * veto

    def stable_softmax(scores, inv_temp):
        scores = np.asarray(scores, dtype=float)
        z = inv_temp * (scores - np.max(scores))
        z = np.clip(z, -30.0, 30.0)
        e = np.exp(z)
        p = e / np.sum(e)
        return p

    beta_t = float(parameters['beta_tally'])
    eps_t = float(parameters['epsilon_tally'])
    p_tally = stable_softmax(np.array([wins_a, wins_b]), beta_t)
    p_tally = (1.0 - eps_t) * p_tally + eps_t * np.array([0.5, 0.5])

    gamma = float(parameters['gamma'])
    weights = np.maximum(validities - 0.5, 0.0) ** gamma
    v = float(np.dot(weights, diff))

    beta_v = float(parameters['beta_v'])
    eps_v = float(parameters['epsilon_v'])
    p_valid = stable_softmax(np.array([v, -v]), beta_v)
    p_valid = (1.0 - eps_v) * p_valid + eps_v * np.array([0.5, 0.5])

    probs = lamb * p_valid + (1.0 - lamb) * p_tally
    probs = np.clip(probs, 0.0, None)
    total = probs.sum()
    if total <= 0.0:
        probs = np.array([0.5, 0.5])
    else:
        probs = probs / total

    return probs

import numpy as np


def policy(probs):
    p = np.asarray(probs, dtype=np.float64)
    p = np.clip(p, 0.0, None)
    total = p.sum()
    if total <= 0.0:
        p = np.ones_like(p) / len(p)
    else:
        p = p / total
    return int(np.random.choice(len(p), p=p))

**Rationale:** This design uses 11 graded experts with mean validity 0.75 and centered validities from -0.25 to +0.25. Eight of the twelve unique pairs are tally ties, d = sum(A - B) = 0, constructed to have large absolute linear validity evidence on tie trials (0.75 to 1.50). The competing context-gated tallying rule therefore sees tie prevalence c = 8/12 = 0.667 and mean tie evidence far above its consistency floor, so after warm-up its validity gate opens to lambda near lambda_max (0.93 to 0.96). The four remaining pairs are critical non-tie crossovers. In C1, d = +3 and S = sum centered_validities * (A - B) = -1.40. In C3, d = +1 and S = -1.50. For the advocated validity-graded integration, D = d + kappa * S with absolute kappa at most 0.10, so C1 gives D between 2.86 and 3.14 and C3 gives D between 0.85 and 1.15; p(A) is therefore above 0.5 for both, and higher for C1 than C3, regardless of kappa sign. For the competing rule with the gate open, the top-validity experts favor B in C1 and C3, so V = sum (v_j - 0.5)^gamma * (A_j - B_j) is negative; p_valid(A) is below 0.5 across the specified gamma and beta_v ranges, and mixing that with the near-1 tally route at lambda around 0.94 keeps overall p(A) below 0.5, typically well below. Thus C1 and C3 produce a sign reversal: advocated theory predicts A-favoring choices, competing theory predicts B-favoring choices once the gate is open. C2 and C4 are exact A/B swaps and give mirrored predictions. The eight d = 0 filler pairs add a second dissociation: advocated theory predicts only small kappa * S shifts around chance, while the gated competing rule predicts strong validity-driven near-1 or near-0 choices after gate opening. Finally, because the competing gate is history-dependent, it predicts a temporal change on the critical crossover pairs from early tally-like choices to later validity-like choices, whereas advocated theory predicts no history effect.

**Computed schedule:** 12 unique pairs × 8 reps = 96 trials per subject.



### METRIC
Rationale:
This metric contrasts validity-following on equal-tally trials with tally-following on unequal-tally trials, after discarding the first 12 trials so the context-gated rule has time to open its validity gate. On tie trials it marks the option favored by validity-weighted evidence, using the fixed communicated validities. On non-tie trials it marks the unweighted tally-majority option. The advocated validity-graded integration rule predicts a negative value: non-tie choices should strongly follow the tally majority (since the small kappa term cannot reverse the tally sign), while tie choices stay near chance on average. The competing context-gated rule predicts a positive value after warm-up: validity experts dominate tie trials, while the validity route pulls or dilutes the critical non-tie choices away from the tally majority. This creates a sign reversal with many trials per subject, yielding a large between-theory gap with relatively low per-subject variance.

import numpy as np
import pandas as pd

def metric(data: pd.DataFrame) -> float:
    df = data.copy()
    df["_order"] = df.groupby("subject_id", sort=False).cumcount()
    df = df[df["_order"] >= 12]
    if df.empty:
        return 0.0

    a = np.asarray(df["option_a_ratings"].tolist(), dtype=float)
    b = np.asarray(df["option_b_ratings"].tolist(), dtype=float)
    d = (a - b).sum(axis=1)
    resp = df["response"].to_numpy().astype(int)

    v = np.array([0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 0.85, 0.75, 0.65, 0.95, 0.99])
    w = v - 0.5

    ties = np.abs(d) < 0.5
    non_ties = ~ties

    if ties.any():
        tie_scores = np.dot(a[ties] - b[ties], w)
        validity_side = np.where(tie_scores > 0, 0, 1)
        tie_rate = float(np.mean(resp[ties] == validity_side))
    else:
        tie_rate = 0.5

    if non_ties.any():
        tally_side = np.where(d[non_ties] > 0, 0, 1)
        non_tie_rate = float(np.mean(resp[non_ties] == tally_side))
    else:
        non_tie_rate = 0.5

    return tie_rate - non_tie_rate

### METRIC
Rationale:
For each subject I fit an ordinary least squares model of the A-choice indicator on two design-derived regressors: d = signed tally advantage of A, and S = centered-validity composition score. I then standardize the fitted d coefficient by its heteroskedasticity-robust standard error, obtaining z_d for that subject. The pooled metric is the population variance of z_d across subjects. Under the advocated context-gated tallying model the tie gate stays closed in this zero-tie design and every subject operates in an unweighted tallying mode with beta_tally bounded in [4.0, 20.0], so d-sensitivity is uniformly strong and the between-subject variance of z_d is moderate. Under validity-graded integration, beta is drawn from [0.1, 20.0], producing a heavy left tail of weakly d-sensitive subjects, especially when kappa and lapse further blur the d contrast. This makes the dispersion of the standardized d-sensitivity z_d substantially larger than under the pure tallying theory. The metric is defined for pooled data as the variance of these subject z-scores, and for a single subject it returns that subject's z_d, which is exactly the unit whose population variance the pooled metric reports.

import numpy as np
import pandas as pd


def metric(data: pd.DataFrame) -> float:
    subjects = list(data['subject_id'].unique())
    z_scores = []
    for sid in subjects:
        sub = data[data['subject_id'] == sid]
        d_vals = []
        s_vals = []
        y_vals = []
        for _, row in sub.iterrows():
            a = np.asarray(row['option_a_ratings'], dtype=float)
            b = np.asarray(row['option_b_ratings'], dtype=float)
            n = a.size
            if n < 2:
                continue
            half = n // 2
            diff = a - b
            high = float(np.sum(diff[:half]))
            low = float(np.sum(diff[half:]))
            d = high + low
            s = 0.25 * (high - low)
            y = 1.0 - float(row['response'])
            d_vals.append(d)
            s_vals.append(s)
            y_vals.append(y)
        if len(y_vals) < 10:
            continue
        X = np.column_stack([
            np.ones(len(y_vals)),
            np.asarray(d_vals, dtype=float),
            np.asarray(s_vals, dtype=float)
        ])
        y = np.asarray(y_vals, dtype=float)
        beta = np.linalg.lstsq(X, y, rcond=None)[0]
        beta = np.asarray(beta, dtype=float).ravel()
        p_hat = X @ beta
        p_hat = np.clip(p_hat, 0.005, 0.995)
        resid = y - p_hat
        XtX = X.T @ X
        try:
            bread = np.linalg.inv(XtX)
        except np.linalg.LinAlgError:
            bread = np.linalg.pinv(XtX)
        meat = (X * (resid ** 2)[:, None]).T @ X
        cov = bread @ meat @ bread
        se_d = float(np.sqrt(max(cov[1, 1], 1e-12)))
        z_d = float(beta[1]) / se_d if se_d > 0 else 0.0
        z_scores.append(z_d)
    if len(z_scores) == 0:
        return 0.0
    if len(subjects) > 1:
        return float(np.var(np.asarray(z_scores, dtype=float), ddof=0))
    return float(z_scores[0])

def metric(data: pd.DataFrame) -> float:
    import numpy as np

    a_col = data['option_a_ratings'].tolist()
    b_col = data['option_b_ratings'].tolist()
    resp = data['response'].astype(int).tolist()

    # Highest validity is at display index 4: [0.57, 0.7, 0.5, 0.77, 0.92, 0.84, 0.63, 0.52]
    top_idx = 4

    xs = []
    ys = []

    for a, b, r in zip(a_col, b_col, resp):
        if a[top_idx] == b[top_idx]:
            continue

        top_is_a = a[top_idx] > b[top_idx]

        a_wins = 0
        b_wins = 0
        for fa, fb in zip(a, b):
            if fa > fb:
                a_wins += 1
            elif fb > fa:
                b_wins += 1

        d = a_wins - b_wins
        if d == 0:
            continue

        # Signed tally advantage for the option favored by the top cue.
        signed_tally_for_top = d if top_is_a else -d

        # 1 if the subject chose the option favored by the top cue, else 0.
        top_chosen = 1.0 if ((top_is_a and r == 0) or ((not top_is_a) and r == 1)) else 0.0

        xs.append(float(signed_tally_for_top))
        ys.append(top_chosen)

    if len(xs) < 2:
        return 0.0

    x = np.asarray(xs, dtype=float)
    y = np.asarray(ys, dtype=float)

    xm = x.mean()
    sxx = float(np.sum((x - xm) ** 2))
    if sxx <= 0:
        return 0.0

    slope = float(np.sum((x - xm) * (y - y.mean())) / sxx)
    return slope

def metric(data: pd.DataFrame) -> float:
    if data.empty:

    validities = np.array([0.5, 0.5, 0.5, 0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.0, 1.0, 1.0], dtype=float)

    total_weight = float(abs_v.sum())
