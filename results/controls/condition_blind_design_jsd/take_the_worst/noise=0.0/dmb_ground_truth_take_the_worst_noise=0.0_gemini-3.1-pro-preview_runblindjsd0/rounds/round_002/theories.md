### slot 1 — `pi_4` — KILLED ✗

**Description:** Equal Weights (Tallying) Heuristic: Decision-makers evaluate options by simply counting the number of positive features (1s) each option possesses, completely ignoring cue validities or any differential weighting. The option with the higher total count of positive features is preferred. If both options have the same number of positive features, the decision-maker guesses randomly. This represents a simple, unweighted compensatory strategy where any positive feature can offset the lack of another. Choice probabilities are generated by applying a softmax function to these unweighted sums, capturing variability in how deterministically the count difference drives choice, while an independent lapse rate accounts for random errors or attentional lapses.

**Rationale:** Following the arbiter's recommendation, this model implements the Equal Weights (Tallying) heuristic. Unlike Take The Best (Theory 1) which relies on a single discriminating cue based on validity, or WADD which integrates all cues weighted by validity, this model simply sums the number of positive features for each option. This provides a purely unweighted compensatory mechanism. For binary features, counting the number of 1s is mathematically equivalent to counting feature-wise wins, but implementing it as an explicit sum over features aligns directly with the Equal Weights formulation. The softmax temperature (beta) scales the difference in total counts, and the lapse rate (epsilon) captures uniform random guessing.

**Parameters:**
  - `beta`: `[0.1, 20.0]`
  - `epsilon`: `[0.0, 0.5]`

```python
def predict(parameters, state, history):
    import numpy as np
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError("Equal Weights expects a (2, n_features) stimulus.")
    
    a, b = stim[0], stim[1]
    
    # Unweighted sum of positive features (Tallying)
    score_a = np.sum(a)
    score_b = np.sum(b)
    scores = np.array([score_a, score_b])
    
    beta = float(parameters["beta"])
    epsilon = float(parameters["epsilon"])
    
    # Numerically stable softmax
    z = beta * (scores - np.max(scores))
    e = np.exp(z)
    p_core = e / np.sum(e)
    
    n_opts = len(p_core)
    return (1.0 - epsilon) * p_core + epsilon * (np.ones(n_opts) / n_opts)
```

**Description:** Take-The-Best (Lexicographic) Heuristic: Decision-makers evaluate features sequentially in order of decreasing cue validity. The first feature that discriminates between the two options strictly determines the preference, and all remaining lower-validity features are ignored. If no features discriminate, the decision-maker guesses randomly. This non-compensatory strategy is formalized by assigning a binary score to the winning option based on the first discriminating cue, which is then mapped to choice probabilities via a softmax function (to capture decision noise) and a uniform lapse rate (to capture random errors).

**Rationale:** Following the arbiter's recommendation, this theory strictly implements the Take-The-Best (Lexicographic) heuristic. It differs from Tallying and WADD by employing a non-compensatory mechanism: cues are checked sequentially from highest to lowest validity, and the search terminates at the first discriminating cue. This single cue dictates the choice, ignoring all other features. The deterministic rule is softened by applying a softmax over the binary TTB scores to capture decision noise, along with an independent lapse rate for random attentional errors.

**Parameters:**
  - `beta`: `[0.1, 20.0]`
  - `epsilon`: `[0.0, 0.5]`
  - `validities`: `validities`

```python
def predict(parameters, state, history):
    import numpy as np
    
    stim = np.asarray(state, dtype=float)
    if stim.ndim != 2 or stim.shape[0] != 2:
        raise ValueError("Take-The-Best expects a (2, n_features) stimulus.")
    
    a, b = stim[0], stim[1]
    validities = np.asarray(parameters["validities"], dtype=float)
    
    # Sort features by validity in descending order
    # stable sort ensures consistent tie-breaking for equal validities
    cue_order = np.argsort(-validities, kind="stable")
    
    score_a = 0.0
    score_b = 0.0
    
    # Evaluate cues sequentially
    for idx in cue_order:
        if a[idx] > b[idx]:
            score_a = 1.0
            break
        elif b[idx] > a[idx]:
            score_b = 1.0
            break

    scores = np.array([score_a, score_b])
    
    # If no cues discriminate, guess randomly
    if score_a == score_b:
        p_core = np.array([0.5, 0.5])
    else:
        beta = float(parameters["beta"])
        z = beta * (scores - np.max(scores))
        e = np.exp(z)
        p_core = e / np.sum(e)
        
    epsilon = float(parameters["epsilon"])
```
