# arbitration

## System Prompt

You are a renowned cognitive scientist arbitrating between two theories across multiple experiments in the Heuristic Decision Making domain.

Each experiment was proposed alongside a metric and an expected outcome. For each experiment you are shown the design, the metric, both theories' predicted metric values (from simulated data), and the observed metric value on real data. The two theories are tagged by stable labels (e.g. "pi_4" and "pi_6") and the same labels are reused on each experiment's predictions.

Each metric value below is shown as `point_estimate (var=X)`, where `point_estimate` is `metric(data)` evaluated on the full pooled dataset and `var` is the population (between-subject) variance of the same metric re-applied per `subject_id`. The point estimate is the canonical scalar; `var` reports how consistent that estimate is across subjects (lower = more consistent). `var=n/a` means the metric could not be applied to a single-subject slice.

The goal of the arbitration is to surface theories that are task-invariant: that is, theories that can explain data across all experiments in the same domain. Perform a deep dive: which among the two theories better captures the observed data?Do not just look at the newest experiments, but look at all experiments together. If a theory is good at explaining all the data keep it. However, if the both theories are good at explaining some experiment but not all, then it might be a good idea to propose a completly new theory that can potentially explain all the data. It is often better to propose a new theory than to propose a new model. Even if one theory is clearly better than the other, instead of proposing a new model, you can propose a new theory that is a stronger competitor to the winning theory instead of proposing a new model. Only propose a new model if both theories are very good and you are confident that the new model will be better than the current one clearly distinguish the two theories.  Then issue a verdict: either "new_model" (keep the current theory description, but regenerate new predict / policy / parameter ranges such that they better capture the observed data across all experiments) or  "new_theory" (the current theory is degenerate; propose a brand-new theory that can better capture the observed data across all experiments). `target_theory_idx` is 1 if you are acting on the theory labelled "pi_4" (THEORY 1 below), or 2 if you are acting on the theory labelled "pi_6" (THEORY 2 below). Justify your choice.


## User Prompt

## EXPERIMENTAL DOMAIN
Subjects repeatedly choose between two fictitious products, A and B. Each option is described by a vector of integer expert ratings in [0, rating_max]. Every experiment fixes its own feature count (via `validities` length), per-expert validities, and `rating_max`; all three are LLM-proposed. Choosing rating_max=1 gives binary ratings; rating_max>1 gives cardinal ratings whose magnitudes carry information beyond just sign. The validities are communicated to the subject in the instructions. Subjects pick whichever product they believe is of higher quality. There is no trial-by-trial correctness feedback.

## THEORY 1 — pi_4
In complex multi-attribute choice tasks without trial-by-trial feedback, subjects may fail to integrate cue validities or magnitudes and instead simply guess with equal probability between the available options. Thus, behavior resembles zero-intelligence random guessing.

def policy(probs):

    probs /= probs.sum()
    return int(np.random.choice(len(probs), p=probs))

## THEORY 2 — pi_6
Response Inertia and Alternation: Subjects in complex, feedback-free multi-attribute choice tasks ignore the stimulus features completely. Instead, their choices are driven by sequential dependencies, where they either exhibit perseveration (a tendency to repeat their previous choice) or alternation (a tendency to switch choices). This results in aggregate choice probabilities that appear as 50/50 random guessing on feature-based metrics, but are mechanistically generated by trial-to-trial memory rather than zero-memory noise.

`predict(parameters, state, history) -> np.ndarray`:
def predict(parameters, state, history):
    import numpy as np
    
    p_repeat = float(parameters["p_repeat"])
    
    if not history or len(history.get("response", [])) == 0:
        return np.array([0.5, 0.5])
        
    last_resp = history["response"][-1]
    
    if last_resp == 0:
        p_A = p_repeat
    else:
        p_A = 1.0 - p_repeat
        
    return np.array([p_A, 1.0 - p_A])

### DESIGN

  trial 8: A=[10, 0, 10, 0]  B=[0, 10, 0, 10]

**Rationale:** To quantitatively dissociate the Random Guessing theory from the Response Inertia theory, we must analyze the sequential dependencies (autocorrelation) of choices across trials. Both theories assume subjects ignore the stimulus features entirely, predicting an overall 50% choice rate for Option A across the experiment. However, Random Guessing posits that each trial is independent (zero memory), predicting that the probability of repeating the previous choice is exactly 0.5. Response Inertia posits that choices depend on the immediately preceding choice, predicting a repeat probability significantly different from 0.5 (either >0.5 for perseveration or <0.5 for alternation). We present a diverse set of trials that strongly dissociate standard feature-based heuristics (TTB, WADD, Tallying, EQW) to ensure that if subjects are actually using feature information, we can capture it, while providing a rigorously randomized sequence to test the trial-to-trial transition probabilities required to separate the two noise-based theories.

**Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
To distinguish Random Guessing from Response Inertia, we look at the sequence of choices. Both theories predict an overall 50% choice rate for each option, but they differ in trial-to-trial dependencies. Random Guessing predicts that the probability of repeating the previous choice is exactly 0.5 (with small binomial variance for finite trials). Response Inertia predicts a repeat probability that systematically deviates from 0.5 (either higher for perseveration or lower for alternation). By calculating the absolute deviation of each subject's repeat rate from 0.5 and averaging across subjects, we get a metric that will be close to 0 under Random Guessing and significantly higher under Response Inertia.

def metric(data: pd.DataFrame) -> float:
    import numpy as np
    deviations = []
    for _, df in data.groupby('subject_id'):
        resp = df['response'].values
        if len(resp) > 1:
            repeats = np.mean(resp[1:] == resp[:-1])
            deviations.append(abs(repeats - 0.5))
    return float(np.mean(deviations)) if deviations else 0.0

However, Random Guessing predicts zero trial-to-trial autocorrelation (a repeat probability of exactly 0.5), while Response Inertia predicts a significant deviation from 0.5 in the probability of repeating the previous choice. **Computed schedule:** 8 unique pairs × 12 reps = 96 trials per subject.



### METRIC
Rationale:
This metric calculates the absolute deviation of each subject's trial-to-trial repeat probability from 0.5. The Competing Theory (Random Guessing) predicts a repeat rate of exactly 0.5, so the expected absolute deviation is close to 0 (driven only by binomial variance). The Advocated Theory (Response Inertia and Alternation) assumes subjects have a fixed tendency to either repeat or alternate, meaning their repeat probability will deviate significantly from 0.5 (e.g., a subject who alternates 80% of the time has a repeat rate of 0.2, yielding a deviation of 0.3). Averaging these absolute deviations across subjects perfectly captures the presence of sequential dependencies regardless of their direction.

```python
def metric(data: pd.DataFrame) -> float:
    import numpy as np
    
    a_ratings = np.array(data['option_a_ratings'].tolist())
    b_ratings = np.array(data['option_b_ratings'].tolist())
    responses = data['response'].values
    
    diff = a_ratings - b_ratings
    
    ttb_choices = np.zeros(len(data), dtype=int) - 1
    for i in range(len(data)):
        for j in range(a_ratings.shape[1]):
            if diff[i, j] > 0:
                ttb_choices[i] = 0
                break
            elif diff[i, j] < 0:
                ttb_choices[i] = 1
                break
                
    valid = ttb_choices != -1
    if not np.any(valid):
        return 0.5
        
    match = (responses[valid] == ttb_choices[valid])
    return float(np.mean(match))
```

```python
    # Calculate the probability of choosing option A (response == 0) for each unique trial
```

```python
    a_ratings = np.stack(data['option_a_ratings'].values)
```

```python
def metric(data: pd.DataFrame) -> float:
    import numpy as np
    
    # Extract ratings into 2D arrays
    a = np.stack(data['option_a_ratings'].values)
    b = np.stack(data['option_b_ratings'].values)
    
    # Calculate the SRF predicted probability of choosing A
    wins = np.sum(a > b, axis=1)
    ties = np.sum(a == b, axis=1)
    p_A = (wins + 0.5 * ties) / a.shape[1]
    
    # Map response to +1 for choosing A (response=0) and -1 for choosing B (response=1)
    choice_sign = 1 - 2 * data['response']
    
    # Calculate the covariance-like product between choice and SRF advantage
    # Random Guessing expected value = 0
    # SRF expected value > 0
    return float(np.mean(choice_sign * (p_A - 0.5)))
```
